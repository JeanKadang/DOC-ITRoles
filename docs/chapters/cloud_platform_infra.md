# Cloud, Platform & Infrastructure

## Purpose

This chapter owns the foundational infrastructure and platform capabilities that underpin all technology delivery. It spans public cloud platforms (Azure, AWS, GCP), container orchestration, virtualisation, server hardware, networking, and FinOps — ensuring scalable, cost-efficient, and resilient infrastructure. The chapter drives platform engineering, observability, and site reliability practices that enable engineering teams to build and operate products at pace.

## Key cross-chapter collaborations

- Partners closely with **DevOps & Delivery** to provide platform foundations (Kubernetes, CI/CD infrastructure, developer experience tooling) that enable fast, reliable software delivery.
- Works with **Security & Identity** to embed security controls, network segmentation, and cloud security posture management into infrastructure design from inception.
- Collaborates with **Data & AI** on shared platform services including AI platform infrastructure, MLOps tooling, and storage architecture that support data workloads at scale.
