# Security & Identity

## Purpose

This chapter owns the organisation's security and identity posture across all platforms and domains. It spans security architecture, DevSecOps, cross-platform security posture management, identity and access management (IAM), privileged access management (PAM), data protection, backup and recovery, and directory services. The chapter ensures that security and identity controls are embedded by design into every layer of the technology estate, enabling the organisation to operate securely and meet its compliance obligations.

## Key cross-chapter collaborations

- Engages with every chapter as a cross-cutting concern — embedding security controls, identity policies, and compliance requirements into infrastructure, delivery pipelines, data platforms, and workplace services.
- Collaborates closely with **Cloud, Platform & Infrastructure** to enforce cloud security posture, network security design, and zero-trust architecture across multi-cloud environments.
- Partners with **DevOps & Delivery** to integrate DevSecOps practices — ensuring security scanning, secrets management, and compliance-as-code are embedded in CI/CD pipelines.
