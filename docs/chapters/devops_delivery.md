# DevOps & Delivery

## Purpose

This chapter owns the engineering practices, toolchains, and application platforms that enable fast, high-quality software delivery. It encompasses CI/CD pipeline engineering, developer experience, application runtime platforms (.NET, Java), API strategy, and enterprise integration — providing the delivery backbone for product and engineering teams. The chapter champions DevOps culture, automation, and continuous improvement across the organisation.

## Key cross-chapter collaborations

- Works closely with **Cloud, Platform & Infrastructure** to align delivery pipelines and developer tooling with underlying platform capabilities and Kubernetes-based runtime environments.
- Partners with **Security & Identity** to embed DevSecOps practices — integrating automated security testing, vulnerability scanning, and compliance gates into delivery pipelines.
- Collaborates with **Service & Governance** to ensure delivery practices align with change management, ITSM processes, and enterprise architecture standards.
