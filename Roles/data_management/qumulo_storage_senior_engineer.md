## Role Overview

The Qumulo Storage Senior Engineer leads the implementation and optimization of complex Qumulo storage solutions. This role provides technical leadership for storage deployments, migrations, and performance tuning while working closely with architects to translate storage designs into effective implementations.

## Role Scope & Boundaries

- **Scope of Influence:** Domain — advanced Qumulo storage solution design and delivery within the Qumulo Storage Architect's reference architecture
- **Experience Anchor:** 5+ years in storage engineering with demonstrated independent delivery on scale-out NAS platforms — operates independently within the Architect's reference architecture
- **Out of Scope:** Qumulo platform architecture and technology standards (Architect-owned); hybrid cloud storage architecture (Cloud Senior Engineers-owned, this role coordinates with it); backup solution design (Backup Solution Senior Engineers-owned, this role coordinates with it)
- **Escalates To:** Qumulo Storage Architect — solution design and implementation strategy exceptions
- **Escalated To By:** Qumulo Storage Engineers on technical implementation issues

## Business Impact

- **Business Objective:** Leads complex Qumulo storage implementations and performance optimisations ensuring enterprise-grade file storage reliability for business-critical applications and data workloads
- **Value Metrics:** Storage availability, complex incident resolution time, data migration success rates, automation coverage, performance improvement metrics, engineer mentorship outcomes
- **Key Stakeholders:** Storage Architect, Qumulo Storage Product Owner, application teams, cloud teams, backup senior engineers, storage engineers
- **Processes Supported:** Complex Qumulo deployments, advanced performance tuning, data migrations, storage automation development, DR and replication implementation, engineer mentorship and knowledge transfer

## Key Responsibilities

- Design and implement complex Qumulo storage solutions based on architectural guidance
- Develop automation for Qumulo management and provisioning
- Lead storage performance optimization and troubleshooting
- Create and maintain storage standards and procedures
- Design and implement advanced data protection strategies
- Lead complex data migration projects to and from Qumulo storage
- Develop storage monitoring and alerting frameworks
- Provide technical mentorship to Qumulo Storage Engineers

## Required Skills & Qualifications

**Technical Skills:**

- Extensive experience with Qumulo storage systems and technologies
- Advanced knowledge of file storage architectures and protocols
- Strong understanding of storage performance optimization
- Experience with storage automation using APIs
- Deep knowledge of data protection and availability technologies
- Advanced troubleshooting skills for complex storage issues
- Understanding of hybrid cloud storage implementations
- Relevant advanced Qumulo certifications or equivalent experience

**Soft Skills and Leadership:**

- Communicates complex Qumulo performance findings, migration plans, and architecture designs clearly to architects, product owners, and application teams; produces thorough technical documentation and runbooks
- Leads cross-functional storage engineering engagements with cloud, backup, and application teams; mentors Qumulo Storage Engineers on advanced automation, performance tuning, and troubleshooting
- Applies systematic and data-driven root-cause analysis to complex Qumulo performance and availability issues; proactively identifies automation opportunities that reduce operational toil

**Technology Proficiency Levels:**

**Expert level required:**

- Advanced Qumulo cluster configuration and performance tuning
- Qumulo REST API and automation frameworks (scripting and integration development)
- data migration planning and execution for complex Qumulo workloads

**Proficient level required:**

- Qumulo Shift for hybrid cloud implementations and data transfers
- Qumulo replication and DR solution design
- Qumulo CloudStudio and custom monitoring and reporting solutions

**Working Knowledge required:**

- Cloud storage platforms (AWS S3, Azure Blob) as Qumulo Shift targets
- Python scripting for Qumulo management automation
- network storage troubleshooting (NFS, SMB, TCP/IP)

**Awareness level expected:**

- Machine learning workload storage patterns for large unstructured datasets
- competitive NAS and object storage platforms
- software-defined storage technology trends
