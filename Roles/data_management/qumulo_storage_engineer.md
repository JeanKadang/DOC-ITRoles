## Role Overview

The Qumulo Storage Engineer is responsible for the implementation, configuration, maintenance, and optimization of the organization's Qumulo storage infrastructure. This role ensures high availability, performance, and reliability of file storage systems while supporting business applications and user needs.

## Business Impact

- **Business Objective:** Implements and maintains Qumulo storage infrastructure ensuring reliable, high-availability file services supporting business applications, user file shares, and data-intensive workloads
- **Value Metrics:** Cluster availability, storage provisioning turnaround, incident resolution time, capacity utilisation efficiency, snapshot and replication success rates
- **Key Stakeholders:** Application teams, virtualisation engineers, backup engineers, network engineers, service desk
- **Processes Supported:** File share provisioning, capacity monitoring, Qumulo cluster maintenance and patching, snapshot management, access control, data migration execution

## Key Responsibilities

- Design, implement, and manage Qumulo storage infrastructure
- Configure and optimize Qumulo clusters for performance and availability
- Implement data protection strategies including snapshots and replication
- Monitor storage capacity and plan for future growth
- Troubleshoot storage-related issues and implement solutions
- Create and maintain documentation for storage systems and procedures
- Implement security best practices for file storage systems
- Collaborate with application teams on storage requirements
- Perform Qumulo software upgrades and patching
- Manage file shares and access controls

## Key Decisions and Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| File share provisioning, quota management, and snapshot scheduling within established standards | Architecture and storage design decisions for complex workloads |
| Routine Qumulo cluster maintenance, software upgrades, and operational monitoring | HA replication design and advanced configuration decisions |
| Storage access control configuration and security hardening execution | Data governance policy and compliance controls for file storage |

## Required Skills & Qualifications

- Experience with enterprise NAS and file storage systems
- Knowledge of file protocols including NFS, SMB, and S3
- Understanding of storage networking concepts
- Experience with performance monitoring and tuning
- Familiarity with data protection concepts including snapshots
- Scripting skills for storage automation (Python preferred)
- Strong troubleshooting and analytical skills
- Solid understanding of storage capacity planning
- Knowledge of storage security best practices
- Good communication and documentation skills

**Technology Proficiency Levels:**

- **Expert level required:** Qumulo Core file system (cluster administration, web UI, CLI, and REST API operations), file protocols (NFS, SMB, and S3 — share provisioning, access controls, and client connectivity), Qumulo snapshot management and replication configuration
- **Proficient level required:** Qumulo Analytics and cluster performance monitoring, Qumulo Shift for cloud data transfers, file system quota management and capacity monitoring, Qumulo software upgrades and patching procedures
- **Working Knowledge required:** Network file system protocol troubleshooting (NFS/SMB connectivity issues), data migration tooling for Qumulo workloads, Python scripting for Qumulo REST API automation
- **Awareness level expected:** Hybrid cloud storage integration patterns, object storage protocol trends (S3-compatible NAS), competitive enterprise NAS platforms (NetApp, Dell EMC Isilon)
