## Role Overview

The Storage Senior Engineer leads the implementation and optimization of complex enterprise storage solutions. This role provides technical leadership for storage deployments, migrations, and operations while working closely with architects to translate storage designs into effective implementations.

## Role Scope & Boundaries

- **Scope of Influence:** Domain — advanced storage solution design and delivery within the Storage Architect's reference architecture
- **Experience Anchor:** 5+ years in storage engineering with demonstrated independent delivery — operates independently within the Architect's reference architecture
- **Out of Scope:** Storage architecture and technology standards (Architect-owned); virtualisation platform design (Virtualization Senior Engineers-owned, this role provides storage to it); backup infrastructure design (Backup Senior Engineers-owned, this role provides storage to it)
- **Escalates To:** Storage Architect — solution design and implementation strategy exceptions
- **Escalated To By:** Storage Engineers on technical implementation issues

## Business Impact

- **Business Objective:** Leads complex enterprise storage implementations and optimisations ensuring high-performance, highly available storage services that support critical business workloads across SAN, NAS, object, and cloud storage platforms
- **Value Metrics:** Storage environment availability, complex incident resolution time, migration success rates, automation coverage, capacity utilisation efficiency, engineer mentorship effectiveness
- **Key Stakeholders:** Storage Architect, application senior teams, virtualisation senior engineers, database senior engineers, backup senior engineers
- **Processes Supported:** Complex storage deployments, advanced performance tuning, multi-platform data migrations, replication/HA implementation, storage automation, technology refresh execution, engineer mentorship

## Key Responsibilities

- Design and implement complex storage solutions based on architectural guidance
- Develop automation for storage provisioning and management
- Lead troubleshooting for critical storage issues
- Create and maintain storage standards and procedures
- Implement advanced data protection and replication strategies
- Optimize storage performance and resource utilization
- Plan and execute storage migrations and technology refreshes
- Provide technical mentorship to Storage Engineers

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Complex storage implementation approach, performance tuning methodology, and automation scripting standards | Storage architecture direction and strategic platform decisions |
| Storage migration planning and execution for complex multi-platform technology refresh and data movement scenarios | Product roadmap input and technology lifecycle recommendations |
| Replication and HA implementation for storage platforms, IaC for storage provisioning | Cloud storage integration strategy and data governance policy adherence |

## Required Skills & Qualifications

- Extensive experience with enterprise storage technologies
- Advanced knowledge of SAN, NAS, and object storage systems
- Strong understanding of storage networking (FC, iSCSI, NVMe-oF)
- Experience with storage automation and orchestration
- Deep knowledge of data protection and replication technologies
- Advanced troubleshooting skills for complex storage environments
- Experience with storage performance optimization
- Relevant advanced certifications from storage vendors

**Technology Proficiency Levels:**

**Expert level required:**

- Enterprise storage arrays (Dell EMC, HPE, NetApp, or Pure Storage — advanced configuration, performance tuning, and replication)
- SAN fabric switches and directors (Fibre Channel zoning, VSAN, and ISL design)
- storage performance analysis and optimisation (IOPS, throughput, queue depth)

**Proficient level required:**

- Software-defined storage (VMware vSAN, Nutanix, or Ceph)
- data replication and mirroring solutions (NetApp SnapMirror, Pure ActiveDR, Zerto)
- storage automation frameworks (Ansible, Terraform for storage provisioning)

**Working Knowledge required:**

- Cloud storage integration technologies (Azure Blob, AWS S3, hybrid storage solutions)
- storage capacity planning and analytics tools
- Kubernetes persistent storage and CSI driver configuration

**Awareness level expected:**

- NVMe-oF protocol and all-flash fabric architecture
- Ceph and Rook-Ceph for cloud-native storage
- AI/ML workload storage patterns for high-throughput environments

## Remote Work Considerations

- **Remote Eligibility:** Hybrid; primarily remote for complex configuration, automation development, and performance analysis; on-site required for hardware refresh, commissioning, and high-risk migration activities
- **Collaboration Tools:** Microsoft Teams, Jira, GitHub, storage management platforms (vendor CLIs/GUIs), Ansible/Terraform for storage automation, and performance monitoring tools
- **On-Site Requirements:** On-site for storage platform hardware refresh, new array commissioning, SAN fabric changes, and major migration tasks
- **Time Zone Flexibility:** Core business hours with some flexibility for maintenance windows and high-risk change windows
- **On-Call / Operational Demands:** On-call rotation for critical storage failures, major performance degradation, and SAN fabric or replication incidents affecting business-critical workloads
