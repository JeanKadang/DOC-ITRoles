## Role Overview

The Storage Engineer implements and maintains enterprise storage solutions across the organization. Working with the Storage Architect and Product Owner, this role ensures reliable, secure, and optimized storage environments supporting various business applications and services.

## Role Scope & Boundaries

- **Scope of Influence:** Team — execution of storage provisioning and connectivity tasks to defined standards
- **Experience Anchor:** 1-3 years in storage or infrastructure engineering — works under guidance, building toward independent delivery
- **Out of Scope:** Storage architecture and solution design (Senior Engineers and the Architect-owned); backup infrastructure integration strategy (Backup Engineers-owned, this role coordinates with it); virtual machine storage design (Virtualization Engineers-owned, this role coordinates with it)
- **Escalates To:** Storage Senior Engineer — design-level questions and complex implementation issues
- **Escalated To By:** application teams on storage requirements and provisioning requests

## Business Impact

- **Business Objective:** Deploys and maintains enterprise storage systems ensuring reliable, performant block, file, and object storage services for servers, virtual machines, and business applications
- **Value Metrics:** Storage system availability, provisioning turnaround time, incident resolution time, capacity utilisation efficiency, change success rate
- **Key Stakeholders:** Application teams, virtualisation engineers, database engineers, service desk, backup engineers
- **Processes Supported:** Storage provisioning, SAN zoning and LUN masking, NAS share management, storage monitoring, maintenance and patching, data migration execution

## Key Responsibilities

- Deploy and configure storage systems according to design specifications
- Implement storage provisioning and allocation based on requirements
- Configure storage networking and connectivity
- Perform routine maintenance on storage infrastructure
- Troubleshoot and resolve storage-related incidents
- Execute storage changes, updates, and migrations
- Implement basic storage automation and scripting
- Document storage configurations and operational procedures

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Storage provisioning, LUN/volume allocation, and NAS file share configuration within established standards | Architecture and platform design decisions |
| Storage system maintenance, software/firmware patching, and operational monitoring | HA design and advanced replication configuration |
| Storage access control implementation, RBAC configuration, and operational documentation | Automation approaches, performance tuning strategies, and security governance |

## Required Skills & Qualifications

- Experience with enterprise storage systems (SAN, NAS, Object)
- Knowledge of storage networking technologies (FC, iSCSI)
- Understanding of storage provisioning and management concepts
- Familiarity with storage monitoring and reporting tools
- Basic scripting skills for storage automation
- Knowledge of data protection principles
- Understanding of storage performance concepts
- Relevant certifications for specific storage platforms

**Technology Proficiency Levels:**

**Expert level required:**

- Enterprise storage provisioning (SAN LUN masking, zoning, and NAS file share creation — Dell EMC, HPE, NetApp, or Pure Storage)
- storage networking (Fibre Channel and iSCSI connectivity and troubleshooting)
- RAID configuration and data protection implementation

**Proficient level required:**

- Storage management software (vendor GUI and CLI tools)
- thin provisioning and deduplication configuration
- storage performance monitoring tools
- cloud storage integration basics

**Working Knowledge required:**

- LUN masking and SAN zoning procedures
- basic scripting for storage automation (Python or PowerShell)
- Kubernetes persistent volume fundamentals

**Awareness level expected:**

- Software-defined storage platforms (VMware vSAN, Ceph basics)
- NVMe-oF for high-performance storage
- object storage platforms (S3-compatible)
