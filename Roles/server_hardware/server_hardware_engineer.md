## Role Overview

The Server Hardware Engineer implements and maintains the physical server infrastructure across the organization. Working with the Server Hardware Architect and Product Owner, this role ensures proper installation, configuration, and maintenance of server hardware to support business applications and services.

## Role Scope & Boundaries

- **Scope of Influence:** Team — execution of server hardware installation, deployment, and inventory tasks to defined standards
- **Experience Anchor:** 1-3 years in server hardware or infrastructure engineering — works under guidance, building toward independent delivery
- **Out of Scope:** Server hardware architecture and solution design (Senior Engineers and the Architect-owned); OS installation ownership (Windows/Linux Server Engineers-owned, this role coordinates with it); vendor contract negotiation (procurement team-owned, this role coordinates receiving and inventory with it)
- **Escalates To:** Server Hardware Architect — implementation activity questions
- **Escalated To By:** data center facilities teams on physical infrastructure coordination

## Business Impact

- **Business Objective:** Deploys and maintains physical server infrastructure ensuring correct hardware builds, firmware compliance, and rapid provisioning to support all platform workloads and business services
- **Value Metrics:** Time to deploy server hardware, hardware availability, firmware compliance rate, configuration accuracy, incident resolution time, asset inventory accuracy
- **Key Stakeholders:** Windows/Linux Server Engineers, virtualisation engineers, data centre facilities teams, service desk
- **Processes Supported:** Server racking and commissioning, BIOS/firmware configuration, hardware maintenance including component replacement, server decommissioning, hardware inventory management

## Key Responsibilities

- Install and rack server hardware according to specifications
- Configure BIOS, firmware, and hardware management interfaces
- Perform hardware troubleshooting and component replacement
- Execute server hardware maintenance tasks
- Assist with hardware inventory management
- Document server configurations and hardware layouts
- Implement physical cable management in data centers
- Support server lifecycle activities including decommissioning

## Key Decisions & Accountabilities

## Required Skills & Qualifications

**Technical Skills:**

- Experience with enterprise server hardware (Dell, HPE, Lenovo, etc.)
- Understanding of server components and architectures
- Knowledge of hardware management interfaces (iDRAC, iLO, etc.)
- Familiarity with data center operations and procedures
- Basic networking knowledge for server connectivity
- Awareness of power and cooling considerations
- Physical aptitude for handling server equipment
- Hardware troubleshooting skills

**Soft Skills and Leadership:**

- Communicates hardware deployment status, incident updates, and configuration documentation clearly to senior engineers, platform teams, and facilities staff
- Collaborates effectively with Windows/Linux engineers, virtualisation engineers, network teams, and data centre facilities to coordinate hardware deployments and maintenance
- Applies systematic hardware troubleshooting to diagnose component failures, firmware issues, and connectivity problems, escalating complex hardware events to senior engineers with organised diagnostic detail

**Technology Proficiency Levels:**

**Expert level required:**

- Enterprise server hardware platforms (Dell PowerEdge, HPE ProLiant, Cisco UCS)
- server management interfaces (iDRAC, iLO, CIMC)
- hardware RAID configurations

**Proficient level required:**

- Server firmware and driver management
- hardware diagnostics utilities
- rack, power, and cooling solutions

**Working Knowledge required:**

- Server deployment tools
- hardware inventory systems
- remote management technologies (IPMI, Redfish)

**Awareness level expected:**

- Composable infrastructure
- hardware automation via Redfish API
- server security technologies (TPM, secure boot)
