## Role Overview

The Server Hardware Architect designs comprehensive server infrastructure strategies and architectures for the organization. This role establishes the technical vision for server hardware implementations, creating architectures that balance performance, scalability, efficiency, and reliability while aligning with business objectives and data center strategies.

## Business Impact

- **Business Objective:** Designs enterprise server hardware architectures ensuring optimal performance, power efficiency, and cost-effectiveness for diverse workload types across data centre environments and hybrid infrastructure
- **Value Metrics:** Server infrastructure availability, hardware refresh on-time delivery, power efficiency improvements (PUE), architecture adoption rate, total cost of ownership trend
- **Key Stakeholders:** CTO, IT leadership, Data Centre Director, FinOps, Infrastructure Product Owner, procurement teams
- **Processes Supported:** Server hardware architecture standards governance, hardware refresh and lifecycle strategy, workload-to-hardware mapping, power and cooling design, vendor evaluation, capacity planning

## Key Responsibilities

- Design enterprise-wide server hardware architectures
- Develop technical strategies for server infrastructure
- Create reference architectures for server deployments
- Design server hardware standardization frameworks
- Establish server hardware refresh and lifecycle strategies
- Design power and cooling optimization approaches
- Evaluate new server technologies and platforms
- Provide technical leadership for server infrastructure initiatives

## Key Decisions and Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Server hardware architecture standards, reference designs, and hardware platform selection | Data centre facility planning, power capacity, and space design |
| Workload-to-hardware mapping, compute performance standards, and hardware sizing methodology | Application infrastructure requirements and virtualisation platform strategy |
| Server hardware refresh lifecycle strategy and technology adoption roadmap | CapEx procurement planning, budget strategy, and vendor commercial decisions |
