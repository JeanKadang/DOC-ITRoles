## Role Overview

The VMware Engineer implements and maintains virtualization infrastructure based on VMware technologies. Working with the VMware Architect and Product Owner, this role ensures reliable, secure, and optimized virtualization services supporting business applications and workloads.

## Role Scope & Boundaries

- **Scope of Influence:** Team — execution of VM provisioning and datastore configuration tasks to defined standards
- **Experience Anchor:** 1-3 years in virtualisation engineering — works under guidance, building toward independent delivery
- **Out of Scope:** VMware architecture and solution design (Senior Engineers and the Architect-owned); server hardware host configuration ownership (Server Hardware Engineers-owned, this role coordinates with it); virtual network implementation ownership (Network Engineers-owned, this role coordinates with it)
- **Escalates To:** VMware Senior Engineer — design-level questions and complex implementation issues
- **Escalated To By:** application teams on VM requirements

## Business Impact

- **Business Objective:** Implements and maintains VMware virtualization environments ensuring reliable virtual machine operations that support application workloads and business services
- **Value Metrics:** VMware environment uptime, VM deployment efficiency, patch compliance rates, backup success rates, incident resolution time
- **Key Stakeholders:** VMware Senior Engineers, application teams, service desk, storage and network teams
- **Processes Supported:** VM provisioning and lifecycle management, vSphere maintenance and patching, vCenter operations, backup and recovery, change management

## Key Responsibilities

- Deploy and configure VMware components according to design specifications
- Implement virtual machine provisioning and management
- Configure resource pools and virtual infrastructure organization
- Perform routine maintenance on VMware infrastructure
- Troubleshoot and resolve virtualization-related incidents
- Execute VMware patches, updates, and upgrades
- Implement basic automation for repetitive virtualization tasks
- Document VMware configurations and operational procedures

## Key Decisions and Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Day-to-day VM provisioning, vCenter configuration, and operational tasks within established standards | Technical configuration and architecture decisions above standard patterns |
| vSphere patching, VMware Update Manager execution, and routine maintenance procedures | Advanced automation approaches and PowerCLI scripting strategy |
| Operational documentation accuracy and change management execution for VMware tasks | Performance optimization recommendations and capacity planning inputs |

## Required Skills & Qualifications

**Technical Skills:**

- Experience with VMware vSphere administration
- Knowledge of virtual machine deployment and management
- Understanding of virtualization resource management
- Familiarity with VMware backup and recovery procedures
- Basic understanding of virtual networking and storage
- Troubleshooting skills for virtualization issues
- Knowledge of VMware security best practices
- Relevant certifications (VMware Certified Professional)

**Soft Skills and Leadership:**

- Communicates operational status, incident updates, and technical documentation clearly to senior engineers, application teams, and the service desk
- Collaborates effectively with storage, network, hardware, and security teams to complete cross-functional VM provisioning and maintenance tasks
- Applies methodical troubleshooting skills to diagnose vSphere and VM incidents, escalating complex issues appropriately with organized technical context for senior engineers

**Technology Proficiency Levels:**

- **Expert level required:** VMware vSphere (ESXi, vCenter Server) for VM provisioning and daily operational management, Virtual machine lifecycle management including templates, snapshots, and customisation specifications, VMware Lifecycle Manager (vSphere Update Manager) for host patching and compliance baseline management, vSphere networking with Distributed vSwitches and port group configuration
- **Proficient level required:** vSphere storage management (VMFS, NFS datastores, Storage DRS), vSphere resource pools, clusters, DRS, and HA configuration, VMware roles-based access control and permission management, vSphere performance dashboards and monitoring within vCenter Server
- **Working Knowledge required:** VMware NSX-T basics for network virtualisation awareness, vSAN fundamentals for hyperconverged storage operations, PowerCLI for task automation and bulk VM configuration operations
- **Awareness level expected:** VMware Tanzu and container workload capabilities, Broadcom VMware product consolidation and licensing changes for operational planning
