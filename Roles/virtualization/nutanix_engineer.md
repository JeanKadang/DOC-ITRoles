## Role Overview

The Nutanix Engineer implements and maintains hyperconverged infrastructure based on Nutanix technology. Working with the Nutanix Architect and Product Owner, this role ensures reliable, secure, and optimized Nutanix environments supporting various business workloads.

## Business Impact

- **Business Objective:** Implements and maintains Nutanix HCI environments ensuring reliable virtual infrastructure operations that support application workloads and business services
- **Value Metrics:** Cluster uptime, VM provisioning turnaround time, patch and upgrade success rates, automation coverage for routine tasks, incident resolution time
- **Key Stakeholders:** Nutanix Senior Engineers, application teams, server hardware engineers, backup teams
- **Processes Supported:** Nutanix cluster operations, VM provisioning, routine patching and upgrade, backup configuration, monitoring, documentation

## Key Responsibilities

- Deploy and configure Nutanix nodes and clusters
- Implement virtual machine provisioning and management
- Configure Nutanix storage and networking services
- Perform routine maintenance on Nutanix infrastructure
- Troubleshoot and resolve Nutanix-related incidents
- Execute Nutanix updates, patches, and upgrades
- Implement basic automation for Nutanix operations
- Document Nutanix configurations and operational procedures

## Key Decisions and Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Day-to-day Nutanix cluster operations, VM provisioning, and standard configuration tasks | Technical configuration decisions above standard operational patterns |
| Nutanix software update execution, patch compliance, and routine maintenance procedures | Architecture and design decisions for cluster expansion or significant changes |
| Operational documentation accuracy and runbook maintenance for Nutanix procedures | Automation framework design and advanced scripting approaches |

## Required Skills & Qualifications

**Technical Skills:**

- Experience with Nutanix administration and operations
- Knowledge of hyperconverged infrastructure concepts
- Understanding of virtualization technologies
- Familiarity with Nutanix AHV or other hypervisors
- Basic network and storage knowledge
- Troubleshooting skills for infrastructure issues
- Knowledge of infrastructure security best practices
- Relevant certifications (Nutanix Certified Professional)

**Soft Skills and Leadership:**

- Communicates operational status, incident progress, and procedural documentation clearly to senior engineers and application teams requesting infrastructure services
- Collaborates effectively with network, storage, hardware, and security engineers on cross-functional VM provisioning, patching, and maintenance tasks
- Applies methodical troubleshooting when diagnosing Nutanix cluster and VM issues, escalating complex problems to senior engineers with clear, organized technical context

**Technology Proficiency Levels:**

- **Expert level required:** Nutanix AOS and AHV hypervisor for day-to-day cluster operations and maintenance, Nutanix Prism Element and Prism Central for VM provisioning, monitoring, and cluster management, Nutanix Foundation for node imaging and cluster deployment procedures, VM provisioning, template management, and storage container configuration
- **Proficient level required:** Nutanix Flow for VM-level microsegmentation policy configuration, Nutanix Files and Objects for software-defined storage management, Nutanix Move for workload migration execution and cutover, Nutanix REST APIs and automation scripts for routine operational tasks
- **Working Knowledge required:** Nutanix backup and disaster recovery tools configuration and recovery testing, Nutanix Guest Tools installation and management in virtual machines, Nutanix software upgrade execution and patch compliance processes
- **Awareness level expected:** Nutanix Calm blueprints and self-service provisioning automation capabilities, Nutanix Karbon Kubernetes platform administration concepts

- **Remote Eligibility:** Fully remote eligible; Nutanix management is primarily performed through Prism Central and REST APIs
- **Collaboration Tools:** Microsoft Teams, Jira, Nutanix Prism Central, Nutanix REST API tools, and monitoring dashboards
- **On-Site Requirements:** Occasional on-site access for physical node replacement, hardware-level troubleshooting, or new cluster deployment
- **Time Zone Flexibility:** Core business hours alignment with the operations team
- **On-Call / Operational Demands:** Participates in on-call rotation for Nutanix cluster incidents and virtual machine failures affecting business-critical services
