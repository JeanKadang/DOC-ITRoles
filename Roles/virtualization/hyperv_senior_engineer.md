## Role Overview

The Hyper-V Senior Engineer leads complex Microsoft virtualization initiatives, develops automation solutions, and provides technical leadership for the virtualization team. This role focuses on optimization, advanced implementations, troubleshooting critical issues, and mentoring other team members.

## Role Scope & Boundaries

- **Scope of Influence:** Domain — advanced Hyper-V solution design and delivery within the Hyper-V Architect's reference architecture
- **Experience Anchor:** 5+ years in Hyper-V or Windows virtualisation engineering with demonstrated independent delivery — operates independently within the Architect's reference architecture
- **Out of Scope:** Hyper-V platform architecture and standards (Architect-owned); advanced Windows Server configuration ownership (Windows Server Teams-owned, this role collaborates with it); complex network design ownership (Network Teams-owned, this role coordinates with it)
- **Escalates To:** Hyper-V Architect — architecture design and standards development support
- **Escalated To By:** Hyper-V Engineers on technical leadership and mentoring needs

## Business Impact

- **Business Objective:** Leads complex Hyper-V implementations and optimizations ensuring a high-performance, resilient Microsoft virtualization platform that reliably supports enterprise application workloads
- **Value Metrics:** Hyper-V environment availability, VM deployment automation coverage, cluster failover success rates, resource utilization efficiency, migration success rates
- **Key Stakeholders:** Hyper-V Architect, IT operations teams, application teams, Windows Server and storage teams
- **Processes Supported:** Cluster design and operations, HA/DR implementation, PowerShell automation, migration execution, capacity optimization

## Key Responsibilities

- Design and implement complex Hyper-V solutions including clusters and high availability configurations
- Develop automation and orchestration solutions for Hyper-V management
- Lead troubleshooting for critical and complex issues in virtualization environments
- Create and maintain technical standards for Hyper-V deployments
- Optimize Hyper-V performance, resource utilization, and efficiency
- Provide technical mentorship to Hyper-V Engineers
- Evaluate and test new Microsoft virtualization technologies and features
- Lead major upgrades and migrations of Hyper-V environments
- Design and implement advanced monitoring and management solutions
- Create complex PowerShell scripts and automation workflows
- Implement disaster recovery solutions for virtualized environments
- Conduct capacity planning and performance optimization
- Support the Hyper-V Architect in design and architecture activities

- Advanced knowledge of Microsoft Hyper-V architecture and technologies
- Expert-level Windows Server administration skills

- Advanced troubleshooting skills for complex virtualization issues

- Understanding of storage technologies including SANs, SMB, and hyperconverged options

- Leads cross-functional collaboration with Windows Server, storage, network, and cloud teams on complex virtualization projects; mentors junior Hyper-V Engineers effectively
- Applies systematic diagnostic thinking to resolve complex Hyper-V cluster, performance, and storage issues; proactively identifies platform reliability and automation improvement opportunities

**Technology Proficiency Levels:**

**Expert level required:**

- Microsoft Hyper-V at advanced cluster configuration and performance optimisation level

**Proficient level required:**

**Working Knowledge required:**

- Windows Admin Center extensions and performance monitoring integration

- Microsoft Endpoint Configuration Manager integration for VM guest OS management

**Awareness level expected:**

- Azure Stack HCI next-generation capabilities and ARC-enabled services
- Windows Server container integration and Kubernetes on Hyper-V emerging patterns

- **Remote Eligibility:** Fully remote eligible; most Hyper-V management is performed through remote tools and PowerShell remoting
