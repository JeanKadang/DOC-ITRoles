## Role Overview

The Hyper-V Architect is responsible for designing and overseeing the strategic implementation of Microsoft's virtualization technologies across the organization. This role drives technical standards, architecture patterns, and best practices for Hyper-V environments.

## Role Scope & Boundaries

- **Scope of Influence:** Domain-wide — Hyper-V virtualisation platform architecture and technology standards across the chapter
- **Experience Anchor:** 8+ years in virtualisation architecture with demonstrated Hyper-V/Windows platform ownership — operates independently on domain-wide Hyper-V architecture decisions
- **Out of Scope:** VMware or Nutanix virtualisation architecture (VMware/Nutanix Architects-owned — parallel, non-Hyper-V virtualisation ladders); Windows Server infrastructure architecture (Windows Server Teams-owned, this role collaborates on platform integration with it); Azure hybrid cloud integration detail (Cloud Teams-owned, this role integrates with it)
- **Escalates To:** Cloud, Platform & Infrastructure Chapter Lead — chapter-wide priorities and cross-domain investment decisions
- **Escalated To By:** Hyper-V Senior Engineers on architecture design and standards development support

## Business Impact

- **Business Objective:** Designs the Hyper-V virtualization platform enabling infrastructure consolidation, high availability, and cost-efficient workload hosting on Microsoft technologies aligned to the Windows infrastructure strategy
- **Value Metrics:** Infrastructure consolidation ratio, virtual machine density, platform availability, hardware cost reduction, workload migration success rates
- **Key Stakeholders:** CTO, Windows Server teams, application teams, storage architects, network architects, IT leadership
- **Processes Supported:** Virtualization standards governance, VM lifecycle management, HA/DR design, hybrid cloud integration, capacity planning

## Key Responsibilities

- Design enterprise-scale Hyper-V architectures that align with business requirements and IT strategy
- Establish architectural standards, policies, and best practices for Hyper-V deployments
- Create reference architectures and detailed designs for Hyper-V environments
- Evaluate new Microsoft virtualization features and capabilities for potential adoption
- Lead technical decision-making for major Hyper-V infrastructure initiatives
- Collaborate with Windows Server teams to ensure integrated virtualization strategies
- Provide architectural oversight and guidance for complex Hyper-V implementations
- Develop virtualization roadmaps in coordination with product owners and stakeholders
- Consult on disaster recovery and high availability designs for Hyper-V environments
- Define migration strategies from other virtualization platforms to Hyper-V
- Ensure security controls meet organizational standards within Hyper-V environments

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Hyper-V architecture standards, reference designs, and Azure Stack HCI platform strategy | Microsoft enterprise platform strategy and broader Windows infrastructure roadmap |
| Hyper-V disaster recovery and high availability design patterns (Hyper-V Replica, clustering, SRM) | Azure cloud integration, Azure Arc deployment strategy, and hybrid cloud architecture |
| Hyper-V security architecture including Shielded VMs, VBS, and SDN security controls | Storage and networking architecture for virtualized workloads |

## Required Skills & Qualifications

**Technical Skills:**

- Expert-level knowledge of Microsoft Hyper-V architecture and technologies
- Extensive experience with Windows Server technologies and administration
- Deep understanding of virtualization concepts, clustering, and high availability
- Experience with System Center Virtual Machine Manager (SCVMM) and related tools
- Strong knowledge of storage technologies and networking as they relate to virtualization
- Experience with hybrid cloud scenarios integrating Hyper-V with Azure
- Familiarity with PowerShell and automation for Hyper-V management
- Understanding of other virtualization platforms for comparison and integration
- Excellent communication skills to explain technical concepts to various audiences
- Strategic thinking and ability to align technology solutions with business needs

**Soft Skills and Leadership:**

- Communicates complex Hyper-V architectural designs clearly to technical teams and IT leadership, enabling sound infrastructure investment decisions and platform adoption
- Builds collaborative relationships with Windows Server, storage, network, and security teams to ensure cohesive, integrated virtualization architecture across the Microsoft platform
- Applies structured analytical thinking to evaluate virtualization design options, balancing performance, resilience, cost, and operational complexity for each architectural decision

**Technology Proficiency Levels:**

**Expert level required:**

- Microsoft Hyper-V architecture, cluster design, and high availability configuration, System Center Virtual Machine Manager (SCVMM) for enterprise VM fleet and library management, Azure Stack HCI and Storage Spaces Direct (S2D) hyperconverged architecture, Windows Server Failover Clustering for Hyper-V environments

**Proficient level required:**

- Hyper-V Replica and Azure Site Recovery for disaster recovery architecture
- Software-Defined Networking in Windows Server and Hyper-V SDN stack
- Windows Admin Center for centralised management and monitoring
- PowerShell DSC and advanced automation for Hyper-V orchestration

**Working Knowledge required:**

- Azure Arc integration and hybrid cloud connectivity for Hyper-V workloads
- Shielded VMs and Virtualization-Based Security (VBS) for platform security design
- Azure migration tooling for Hyper-V workload cloud integration

**Awareness level expected:**

- Azure Stack HCI next-generation capabilities and evolving licensing
- Emerging containerisation and Kubernetes integration on Windows Server
