## Role Overview

The Application Configuration Management Senior Engineer leads the implementation and optimization of complex configuration management solutions for applications across the enterprise. This role provides technical leadership for creating standardized, repeatable, and secure approaches to managing application settings, parameters, and environmental configurations.

## Role Scope & Boundaries

- **Scope of Influence:** Domain — detailed engineering design and delivery within the configuration management reference architecture
- **Experience Anchor:** 5+ years in configuration/ITSM engineering with demonstrated independent delivery — operates independently within the Architect's reference architecture
- **Out of Scope:** Configuration management reference architecture and automation standards (Architect-owned); DevOps CI/CD toolchain decisions (DevOps-owned); ITSM platform commercial decisions (ITSM Product Owner-owned)
- **Escalates To:** Configuration Management Architect — architecture-level questions and standards exceptions
- **Escalated To By:** Configuration Management Engineers on complex configuration and implementation issues

## Business Impact

- **Business Objective:** Leads complex application configuration management implementations, automation frameworks, and secure configuration practices ensuring enterprise-grade consistency, compliance, and reliability across all application environments
- **Value Metrics:** Configuration management reliability, automation coverage, configuration deployment success rate, security compliance of configuration processes, engineer mentorship effectiveness
- **Key Stakeholders:** Configuration Management Architect, DevOps Senior Engineers, Security Engineers, ITSM Product Owner, application teams
- **Processes Supported:** Complex configuration management implementation, secret management and configuration security, CI/CD configuration integration, configuration drift detection, governance controls, engineer mentorship

## Key Responsibilities

- Design and implement complex application configuration management solutions
- Develop frameworks for managing configurations across application lifecycles
- Create technical specifications for configuration management workflows
- Lead troubleshooting for critical configuration management issues
- Establish standards for configuration management across environments
- Implement governance controls in configuration processes
- Optimize configuration management for security and compliance
- Provide technical mentorship to Configuration Management Engineers
