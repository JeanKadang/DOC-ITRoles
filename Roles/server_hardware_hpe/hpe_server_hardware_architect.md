## Role Overview

The HPE Server Hardware Architect designs and oversees the organization's server infrastructure based on Hewlett Packard Enterprise technologies. This role ensures the delivery of a reliable, performant, and cost-effective server platform that meets the organization's computing requirements.

## Role Scope & Boundaries

- **Scope of Influence:** Domain-wide — HPE server hardware standards and technology roadmap across the chapter
- **Experience Anchor:** 8+ years in server hardware architecture with demonstrated HPE platform ownership — operates independently on domain-wide HPE hardware architecture decisions
- **Out of Scope:** Vendor-agnostic server hardware architecture (Server Hardware Architect-owned — a parallel, non-HPE hardware ladder); OS-level configuration on the hardware (Windows and Linux Server Architects-owned, this role aligns hardware to it); virtualisation host design detail (VMware/Nutanix Architects-owned, this role provides hardware requirements to it)
- **Escalates To:** Cloud, Platform & Infrastructure Chapter Lead — chapter-wide priorities and cross-domain investment decisions
- **Escalated To By:** HPE Server Hardware Senior Engineers on solution design and implementation strategy

## Business Impact

- **Business Objective:** Designs enterprise HPE server hardware architectures delivering optimised, reliable compute platforms using HPE ProLiant, Synergy, and BladeSystem technologies aligned with diverse workload requirements and business growth objectives
- **Value Metrics:** HPE server infrastructure availability, hardware refresh on-time delivery, power efficiency improvements (PUE), architecture standards adoption rate, total cost of ownership trend
- **Key Stakeholders:** CTO, IT leadership, Infrastructure Product Owner, Data Centre Director, Windows/Linux/VM Architects
- **Processes Supported:** HPE server architecture standards governance, hardware platform selection and evaluation, workload-to-hardware design, lifecycle strategy, power and cooling design, HPE vendor engagement

## Key Responsibilities

- Design and architect HPE server solutions including ProLiant, Synergy, and BladeSystem
- Develop hardware standards and specifications for different workloads
- Create server infrastructure designs aligned with business requirements
- Plan and architect server hardware refreshes and migrations
- Optimize server hardware configurations for performance and efficiency
- Design hardware management and monitoring solutions
- Develop server hardware lifecycle management strategies
- Provide technical leadership for HPE server infrastructure initiatives

## Required Skills & Qualifications

**Technical Skills:**

- Deep knowledge of HPE server products and technologies
- Extensive experience with enterprise server hardware design
- Understanding of server processor, memory, and storage architectures
- Knowledge of HPE management tools and frameworks
- Experience with server performance optimization
- Familiarity with data center infrastructure requirements
- Understanding of high availability and fault tolerance at hardware level
- Relevant certifications (HPE ASE - Server Solutions Architect, etc.)

**Soft Skills and Leadership:**

- Communicates HPE server architecture decisions and hardware strategies clearly to IT leadership, platform architects, and HPE vendor teams; produces comprehensive reference architectures and standards documentation
- Collaborates with Windows/Linux/VM architects, data centre teams, network architects, and storage architects ensuring HPE hardware designs support all platform requirements and future workload needs
- Evaluates HPE technology roadmaps critically, designs for future capacity requirements, and identifies architecture improvements that reduce operational risk and total infrastructure cost
