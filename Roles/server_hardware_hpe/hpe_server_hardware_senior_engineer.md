## Role Overview

The HPE Server Hardware Senior Engineer leads the implementation and optimization of enterprise server infrastructure based on Hewlett Packard Enterprise technologies. This role provides technical leadership for complex server deployments, migrations, and operations while working closely with architects to translate server designs into effective implementations.

## Business Impact

- **Business Objective:** Leads complex HPE server hardware deployments, OneView automation, and capacity planning ensuring reliable, performant HPE ProLiant and Synergy infrastructure supporting all business workload platforms
- **Value Metrics:** Hardware availability, complex incident resolution time, firmware compliance rate, automation coverage, refresh project success rates, power efficiency improvements
- **Key Stakeholders:** HPE Server Hardware Architect, platform senior engineers (Windows/Linux/VM/HPC), FinOps, data centre facilities
- **Processes Supported:** Complex HPE server builds and deployments, OneView and iLO automation, capacity planning, advanced hardware troubleshooting, hardware lifecycle refresh execution, HPE engineer mentorship

## Key Responsibilities

- Design and implement complex HPE server solutions based on architectural guidance
- Develop automation for server deployment and configuration management
- Lead server hardware migrations and technology refresh projects
- Create and maintain server hardware standards and procedures
- Lead troubleshooting for critical hardware issues
- Implement advanced HPE management and monitoring solutions
- Optimize server configurations for performance, efficiency, and availability
- Provide technical mentorship to HPE Server Hardware Engineers

## Key Decisions and Accountabilities

## Required Skills & Qualifications

**Technical Skills:**

- Extensive experience with HPE server technologies
- Advanced knowledge of HPE server architectures and management frameworks
- Strong understanding of server component technologies and configurations
- Experience with server automation and scripting
- Deep knowledge of HPE firmware and driver management
- Advanced troubleshooting skills for complex hardware issues
- Knowledge of data center infrastructure constraints
- Relevant advanced certifications (HPE ASE - Server Solutions Architect)

**Soft Skills and Leadership:**

- Communicates complex HPE hardware design decisions, capacity analysis, and project status clearly to architects, product owners, and cross-platform engineering teams; produces thorough hardware standards and automation documentation
- Leads cross-functional HPE hardware projects with platform teams, data centre facilities, network, and HPE technical resources; mentors HPE Server Hardware Engineers on advanced troubleshooting, firmware lifecycle management, and OneView automation
- Applies systematic root-cause analysis to complex HPE hardware failures; proactively identifies firmware automation and hardware standardisation opportunities that reduce provisioning time and operational risk
