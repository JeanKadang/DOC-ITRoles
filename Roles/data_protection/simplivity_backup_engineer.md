## Role Overview

The SimpliVity Backup Engineer implements and maintains backup and recovery operations using HPE SimpliVity's built-in capabilities. Working with the SimpliVity Backup Architect and Product Owner, this role ensures reliable data protection for workloads running on the SimpliVity platform.

## Role Scope & Boundaries

- **Scope of Influence:** Team — execution of SimpliVity backup configuration and VM backup operation tasks to defined standards
- **Experience Anchor:** 1-3 years in backup or virtualisation engineering — works under guidance, building toward independent delivery
- **Out of Scope:** SimpliVity architecture and solution design (Senior Engineers and the Architect-owned); VM-level backup operations ownership (VMware Engineers-owned, this role coordinates with it); backup monitoring tooling design (Observability Engineers-owned, this role implements monitoring within it)
- **Escalates To:** SimpliVity Backup Senior Engineer — design-level questions and complex implementation issues
- **Escalated To By:** application teams on backup and recovery requirements

## Business Impact

- **Business Objective:** Implements and operates SimpliVity's native backup and recovery capabilities ensuring reliable VM data protection and recovery for all SimpliVity-hosted workloads and business systems
- **Value Metrics:** VM backup success rate, recovery turnaround time, backup policy coverage, replication health status, monthly recovery test pass rate
- **Key Stakeholders:** VMware engineers, application teams, service desk, SimpliVity Backup Architect, SimpliVity infrastructure teams
- **Processes Supported:** Backup policy configuration and management, daily backup monitoring and failure resolution, recovery execution, replication management, backup documentation

## Key Responsibilities

- Configure and manage SimpliVity backup policies and schedules
- Implement SimpliVity backup retention strategies
- Monitor daily SimpliVity backup operations and troubleshoot failures
- Execute recovery operations for SimpliVity-hosted workloads
- Configure SimpliVity replication for disaster recovery
- Perform routine maintenance on SimpliVity backup components
- Execute backup testing and validation procedures
- Document SimpliVity backup configurations and operational procedures
