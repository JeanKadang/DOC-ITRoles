## Role Overview

The SimpliVity Backup Senior Engineer leads the implementation and optimization of data protection solutions using HPE SimpliVity's built-in capabilities. This role provides technical leadership for complex SimpliVity backup deployments while working closely with architects to translate data protection strategies into effective implementations.

## Role Scope & Boundaries

- **Scope of Influence:** Domain — advanced SimpliVity backup solution design and delivery within the SimpliVity Backup Architect's reference architecture
- **Experience Anchor:** 5+ years in backup engineering with demonstrated independent SimpliVity delivery — operates independently within the Architect's reference architecture
- **Out of Scope:** SimpliVity platform architecture and technology standards (Architect-owned); advanced VMware virtualisation integration ownership (VMware Senior Engineers-owned, this role coordinates with it); broader enterprise backup strategy (Enterprise Backup Senior Engineers-owned, this role integrates with it)
- **Escalates To:** SimpliVity Backup Architect — solution design and implementation strategy exceptions
- **Escalated To By:** SimpliVity Backup Engineers on technical implementation issues

## Business Impact

- **Business Objective:** Leads complex SimpliVity data protection implementations and troubleshooting ensuring enterprise-grade VM backup reliability, replication performance, and recovery capabilities for business-critical workloads
- **Value Metrics:** VM backup availability, complex incident resolution time, RPO/RTO testing success, automation coverage, storage deduplication efficiency, recovery test pass rate
- **Key Stakeholders:** SimpliVity Backup Architect, VMware senior engineers, application teams, SimpliVity Backup Engineers, SimpliVity Backup Product Owner
- **Processes Supported:** Complex SimpliVity deployments, DR replication implementation, backup automation development, performance optimisation, recovery orchestration, engineer mentorship

## Key Responsibilities

- Design and implement complex SimpliVity backup solutions based on architectural guidance
- Develop automation for SimpliVity backup operations
- Lead troubleshooting for critical SimpliVity backup and recovery issues
- Create and maintain SimpliVity backup standards and procedures
- Implement advanced recovery strategies for SimpliVity environments
- Optimize SimpliVity backup performance and resource utilization

- Provide technical mentorship to SimpliVity Backup Engineers
