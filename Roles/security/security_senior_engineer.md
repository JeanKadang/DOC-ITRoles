## Role Overview

The Security Senior Engineer leads the implementation and optimization of complex security solutions across the organization. This role provides technical leadership for security deployments, operations, and incident response while working closely with architects to translate security designs into effective implementations.

## Role Scope & Boundaries

- **Scope of Influence:** Domain — advanced security solution design and delivery within the Security Architect's reference architecture
- **Experience Anchor:** 5+ years in security engineering with demonstrated independent delivery — operates independently within the Architect's reference architecture
- **Out of Scope:** Security architecture and control framework design (Architect-owned); incident response process ownership (Incident Response-owned, this role coordinates on security events); network security infrastructure design (Network Senior Engineers-owned, this role coordinates with it)
- **Escalates To:** Security Architect — solution design exceptions
- **Escalated To By:** Security Engineers on technical implementation issues

## Business Impact

- **Business Objective:** Strengthens the organisation's security posture by implementing advanced detection, response, and protection capabilities that reduce dwell time, contain breaches quickly, and ensure security tooling operates at peak effectiveness.
- **Value Metrics:** Mean time to detect (MTTD) and respond (MTTR) to security incidents, SIEM/SOAR detection coverage, security automation playbook effectiveness, vulnerability remediation SLA compliance, critical finding remediation rate.
- **Key Stakeholders:** Security Architect, Security Product Owner, SOC team, Cloud and Network Senior Engineers, application teams.
- **Processes Supported:** Security incident response (P1/P2 lead), threat hunting, vulnerability management, SIEM/SOAR tuning, security automation, DevSecOps toolchain integration.

## Key Responsibilities

- Design and implement complex security solutions
- Lead security technology deployments and integrations
- Develop security automation and orchestration workflows
- Lead troubleshooting for critical security issues
- Create and maintain security standards and procedures
- Implement advanced threat detection capabilities

- Provide technical mentorship to Security Engineers

## Remote Work Considerations

- **Remote Eligibility:** Hybrid — primarily remote; occasional on-site for sensitive incident response, physical security assessments, or data centre security reviews.
- **Collaboration Tools:** Microsoft Teams, Jira, Confluence, GitHub, SIEM console (Microsoft Sentinel / Splunk), SOAR platform, threat intelligence platforms.
- **On-Site Requirements:** Occasional data centre or secure facility access for hardware security assessments or forensic evidence handling.
- **Time Zone Flexibility:** Standard business hours; on-call rotation across the team.
- **On-Call / Operational Demands:** P1/P2 on-call rotation for security incidents; leads containment, investigation, and recovery; participates in post-incident review.
