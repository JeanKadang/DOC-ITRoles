# Security domain

This domain covers general security architecture across the organisation — threat modelling and risk assessment, security controls frameworks, SIEM and SOC architecture, incident response frameworks, penetration testing governance, vulnerability management, and cross-organisation security policies. Roles in this domain are the primary owners of the organisation-wide security posture and are the escalation point for security standards that do not belong exclusively to identity management or cross-platform security automation. For platform-spanning security patterns see `security_cross_platform/`; for identity and access management see `security_identity/`.
