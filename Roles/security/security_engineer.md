## Role Overview

The Security Engineer implements and maintains security controls and technologies across the organization's IT infrastructure. Working with Security Architects and Senior Engineers, this role ensures the effective deployment of security solutions that protect systems, data, and users while supporting business requirements.

## Role Scope & Boundaries

- **Scope of Influence:** Team — execution of security control implementation tasks to defined standards
- **Experience Anchor:** 1-3 years in security engineering — works under guidance, building toward independent delivery
- **Out of Scope:** Security architecture and solution design (Senior Engineers and the Architect-owned); network-level security control ownership (Network Engineers-owned, this role coordinates with it); identity access control design (Identity Engineers-owned, this role coordinates with it)
- **Escalates To:** Security Senior Engineer — design-level questions and complex implementation issues
- **Escalated To By:** application teams on security implementation requests

## Business Impact

- **Business Objective:** Implements and maintains the security controls that protect the organisation's systems, data, and users from cyber threats, reducing attack surface area and ensuring security tooling and policies are operational and effective.
- **Value Metrics:** Vulnerability remediation rate and age, security alert response time, security patch compliance rate, EDR coverage percentage, documentation and runbook completeness.
- **Key Stakeholders:** Security Senior Engineer, Security Product Owner, IT operations teams, service desk, application development teams.
- **Processes Supported:** Vulnerability management, security patching, incident response (first response), security compliance auditing, endpoint protection operations, access control administration.

## Key Responsibilities

- Implement security controls and technologies
- Configure security tools and monitoring systems
- Perform vulnerability assessments and remediation
- Assist with security incident response
- Deploy endpoint security solutions
- Implement identity and access management controls
- Support security compliance and audit activities
- Create and maintain security documentation
- Support application security testing

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Day-to-day security tool configuration, alert triage, and routine vulnerability remediation | Complex security solution design (escalated to Senior Engineer / Architect) |
| Security documentation, runbooks, and operational procedures | Security policy definition and risk acceptance decisions |
| Endpoint security deployment and patch management within agreed standards | Security architecture and technology selection |

## Remote Work Considerations

- **Remote Eligibility:** Hybrid — primarily remote; physical access required for data centre hardware security tasks and endpoint provisioning.
- **Collaboration Tools:** Microsoft Teams, ServiceNow (ticketing), Jira, Confluence, Microsoft Defender portal, vulnerability scanning console.
- **On-Site Requirements:** Occasional data centre or office access for hardware security inspections, physical media handling, or on-site incident support.
- **Time Zone Flexibility:** Standard business hours; may participate in shift coverage for security monitoring.
- **On-Call / Operational Demands:** May participate in on-call rota for security alerts; escalates P1 incidents to Security Senior Engineer.
