## Role Overview

The Security Architect designs and implements security systems and frameworks that protect the organization's information assets and technology infrastructure. They establish security standards, patterns, and best practices while ensuring compliance with regulatory requirements and industry standards.

## Role Scope & Boundaries

- **Scope of Influence:** Domain-wide — enterprise security architecture, control frameworks, and security design standards across the chapter
- **Experience Anchor:** 8+ years in security architecture or engineering with demonstrated architecture-level delivery — operates independently on domain-wide security architecture decisions
- **Out of Scope:** Enterprise-wide architecture integration beyond security (Enterprise Architects-owned, this role provides security patterns into it); regulatory interpretation (Compliance Managers-owned, this role implements requirements); security investment prioritisation (Security Product Owner-owned)
- **Escalates To:** Security & Identity Chapter Lead — chapter-wide priorities and cross-domain investment decisions
- **Escalated To By:** Security Senior Engineers on solution design and implementation strategy

## Business Impact

- **Business Objective:** Protects the organisation's information assets, technology infrastructure, and reputation by designing security controls and frameworks that reduce the risk of breaches, ensure regulatory compliance, and enable the business to operate and grow with confidence.
- **Value Metrics:** Reduction in critical and high vulnerabilities, security architecture compliance rate, time to complete security design reviews, number of security incidents attributable to design gaps, regulatory audit pass rate.
- **Key Stakeholders:** CISO, CTO, Board Risk Committee, Legal and Compliance, Cloud and Platform Architects, business unit leads, application development teams.
- **Processes Supported:** Project architecture review (security gate), risk assessment and treatment, regulatory compliance (GDPR, NIS2, DORA, PCI-DSS), third-party security assessment, security roadmap planning.

## Key Responsibilities

- Design comprehensive security architecture aligned with business goals
- Evaluate and recommend security technologies and solutions
- Create security patterns and reference architectures
- Ensure security compliance across all IT infrastructure
- Develop security roadmaps and implementation plans
- Advise on security implications for new projects and AI/LLM deployments
- Evaluate and enforce AI security controls including prompt injection defenses and LLM governance
- Lead security architecture reviews and risk assessments
- Collaborate on disaster recovery and business continuity planning

## Key Decisions and Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Enterprise security architecture standards, reference designs, and controls library | Application and infrastructure architecture decisions (with domain architects) |
| Security technology selection and security toolchain strategy | Risk appetite and tolerance thresholds (with CISO / Risk Management) |
| Threat modelling methodology and AI/LLM security control framework | Regulatory interpretation and legal obligations (with Legal / Compliance) |

## Required Skills & Qualifications

- Extensive knowledge of security frameworks (NIST CSF 2.0, IEC 62443, ISO 27001, MITRE ATT&CK)
- Strong understanding of network, cloud, and application security
- Experience with security architecture methodologies and tools
- Familiarity with regulatory requirements (GDPR, PCI-DSS, HIPAA, DORA, NIS2)
- Knowledge of encryption technologies and key management
- Understanding of IAM principles and zero trust architectures
- Understanding of AI/ML security risks including prompt injection, model theft, and adversarial attacks
- Advanced troubleshooting and problem-solving abilities
- Excellent communication and stakeholder management skills

**Technology Proficiency Levels:**

**Expert level required:**

- Zero trust architecture (ZTNA, microsegmentation, identity-centric access)
- Identity-centric security (IAM, Microsoft Entra ID, PIM, Conditional Access)
- Threat modelling (STRIDE, PASTA, MITRE ATT&CK-based design reviews)

**Proficient level required:**

- SIEM / SOAR platforms (Microsoft Sentinel, Splunk, Palo Alto XSOAR)
- Cloud Security Posture Management (CSPM) and CNAPP
- SC-100 domains (Microsoft Cybersecurity Architect Expert syllabus)

**Working Knowledge required:**

- MITRE ATLAS (adversarial threat landscape for AI systems)
- Prompt injection defences and LLM security controls

**Awareness level expected:**

- EU AI Act compliance requirements and obligations for high-risk AI systems

## Remote Work Considerations

- **Remote Eligibility:** Hybrid — primarily remote; occasional on-site for sensitive architecture reviews, regulatory engagements, or board-level risk presentations.
- **Collaboration Tools:** Microsoft Teams, Confluence, Microsoft Threat Modeling Tool / STRIDE frameworks, Jira, GitHub.
- **On-Site Requirements:** Occasional secure facility access for classified or regulated workload design; data centre visits for physical security assessments.
- **Time Zone Flexibility:** Standard business hours; available for urgent security incident architectural guidance.
- **On-Call / Operational Demands:** On-call for P1 security incidents requiring architectural assessment or emergency design guidance; participates in major incident review.
