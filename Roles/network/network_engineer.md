## Role Overview

The Network Engineer implements and maintains enterprise network infrastructure across the organization. Working with the Network Architect and Product Owner, this role ensures reliable, secure, and optimized network connectivity supporting various business applications and services.

## Role Scope & Boundaries

- **Scope of Influence:** Team — execution of network connectivity and configuration tasks to defined standards
- **Experience Anchor:** 1-3 years in network engineering — works under guidance, building toward independent delivery
- **Out of Scope:** Network architecture and solution design (Senior Engineers and the Architect-owned); network security control implementation (Security Engineers-owned, this role coordinates with it); server connectivity ownership (Server Infrastructure Engineers-owned, this role coordinates with it)
- **Escalates To:** Network Senior Engineer — design-level questions and complex implementation issues
- **Escalated To By:** business units on network connectivity requirements

## Business Impact

- **Business Objective:** Maintains day-to-day network connectivity across the organisation, ensuring reliable access to business applications, internet services, and inter-site communication for all users and systems.
- **Value Metrics:** Network uptime contribution, mean time to resolve standard connectivity incidents, change implementation success rate, documentation completeness, service request fulfilment lead time.
- **Key Stakeholders:** Network Senior Engineer, Network Product Owner, end users, site and facilities teams, IT service desk.
- **Processes Supported:** Incident management (first-line network support), change management (standard and low-risk changes), service request fulfilment, asset and configuration record maintenance.

## Key Responsibilities

- Deploy and configure network devices according to design specifications
- Implement routing, switching, and wireless connectivity solutions
- Configure network security controls and access policies
- Perform routine maintenance on network infrastructure
- Troubleshoot and resolve network connectivity issues
- Execute network changes, updates, and migrations
- Implement basic network automation and monitoring
- Document network configurations and operational procedures

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Standard network configuration changes, VLAN provisioning, and IP assignments | Complex network solution design (escalated to Senior Engineer / Architect) |
| Routine firewall rule implementation within approved security policy | Network security policy and segmentation strategy |
| Network device monitoring and first-response incident triage | Network technology selection and roadmap planning |

## Required Skills & Qualifications

- Experience with enterprise network equipment (routers, switches, firewalls)
- Knowledge of routing and switching protocols
- Understanding of network security principles
- Familiarity with WAN and LAN technologies
- Basic scripting skills for network automation
- Knowledge of network monitoring tools
- Understanding of wireless networking concepts
- Relevant certifications (CCNA, JNCIA, etc.)

**Awareness level expected:**

## Remote Work Considerations

- **Remote Eligibility:** Hybrid — remote for configuration, monitoring, and documentation work; on-site required for physical cabling, hardware installation, and data centre activities.
- **Collaboration Tools:** Microsoft Teams, ServiceNow (ticketing), Jira, Confluence, network monitoring tools (PRTG, SolarWinds, Nagios).
- **On-Site Requirements:** Regular data centre, IDF, and MDF access for physical network tasks; branch or campus site visits for installations and fault resolution.
- **Time Zone Flexibility:** Standard business hours; may participate in shift or out-of-hours rota for maintenance windows.
- **On-Call / Operational Demands:** May participate in on-call rota for after-hours network incidents; escalates P1/P2 issues to the Senior Engineer.
