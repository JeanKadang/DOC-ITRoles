## Role Overview

The Network Architect designs comprehensive enterprise network strategies and architectures for the organization. This role establishes the technical vision for network infrastructure, creating architectures that balance performance, security, scalability, and reliability while aligning with business objectives and digital transformation initiatives.

## Role Scope & Boundaries

- **Scope of Influence:** Domain-wide — network architecture, connectivity standards, and hybrid network design across the chapter
- **Experience Anchor:** 8+ years in network architecture with demonstrated architecture-level delivery — operates independently on domain-wide network architecture decisions
- **Out of Scope:** Network automation tooling architecture (Network Automation Architect-owned — a peer role that extends and operationalises this role's designs); security control implementation (Security Architects-owned, this role implements security design from it); cloud connectivity service selection (Cloud Architects-owned, this role aligns hybrid connectivity to it)
- **Escalates To:** Cloud, Platform & Infrastructure Chapter Lead — chapter-wide priorities and cross-domain investment decisions
- **Escalated To By:** Network Senior Engineers on solution design and implementation strategy

## Business Impact

- **Business Objective:** Ensures the organisation has a resilient, scalable, and secure network foundation that enables reliable connectivity for all business services, digital transformation initiatives, and cloud-hybrid workloads.
- **Value Metrics:** Network availability (target 99.99%), reduction in unplanned outages, cost per unit of bandwidth, time-to-deploy new network services, security incidents attributable to network design gaps.
- **Key Stakeholders:** CTO / IT Director, Cloud Architects, Security Architects, application and platform teams, site and facilities operations.
- **Processes Supported:** Major project delivery (network design sign-off), technology lifecycle management, capacity planning, security architecture review, cloud migration design.

## Key Responsibilities

- Design enterprise-wide network architectures
- Develop technical strategies for network infrastructure
- Create reference architectures for network implementations
- Design network security architectures and frameworks
- Establish network segmentation and isolation strategies
- Design hybrid and multi-cloud network connectivity
- Evaluate new network technologies and approaches
- Provide technical leadership for network initiatives
- Design edge networking architectures: SD-WAN edge PoP topology, 5G and private 5G integration for industrial and IoT edge sites, and cloud edge compute connectivity patterns (Azure Edge Zones, AWS Wavelength, AWS Local Zones).
- Define network security architecture for edge environments: micro-segmentation at edge PoPs, zero trust network access for edge workloads, and secure SD-WAN policy enforcement at distributed edge sites.
