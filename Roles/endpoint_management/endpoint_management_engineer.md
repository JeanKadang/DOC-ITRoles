## Role Overview

The Endpoint Management Engineer administers and maintains the organisation's enterprise endpoint management platform, ensuring devices are enrolled, configured, patched, and compliant with security policies. This role operates Microsoft Intune and MECM/SCCM day-to-day, deploying applications, enforcing compliance, and supporting the help desk with endpoint issues across Windows, macOS, iOS, and Android devices.

## Business Impact

- **Business Objective:** Keep the device estate healthy, secure, and compliant to enable workforce productivity and reduce organisational risk.
- **Value Metrics:** Device compliance rate, patch deployment success rate, application deployment success rate, help desk escalation volume.
- **Key Stakeholders:** Help Desk, End Users, IT Operations, Security Operations.
- **Processes Supported:** Device provisioning, patch management, application deployment, compliance reporting, user onboarding.

## Key Responsibilities

- Administer Microsoft Intune policies, compliance rules, and configuration profiles across managed device platforms.
- Manage application deployment through Intune Company Portal and MECM Software Centre.
- Monitor device compliance status and remediate non-compliant devices in accordance with policy.
- Assist with Windows Autopilot device registration and troubleshoot enrolment failures.
- Deploy and manage endpoint patches using Intune Autopatch or MECM software update management.
- Maintain device inventory and generate compliance and deployment reports.
- Write and deploy PowerShell scripts for endpoint remediation tasks via Intune.
- Support help desk escalations related to device management, app installation, and policy conflicts.
- Manage Apple Business Manager integration and iOS/macOS enrolment workflows.
- Maintain runbooks, SOPs, and endpoint management knowledge base articles.
- Participate in change management processes for endpoint configuration changes.

## Required Skills

**Technical Skills:**

- Working knowledge of Microsoft Intune device management - configuration profiles, compliance policies, app deployment.
- Familiarity with Microsoft Endpoint Configuration Manager (MECM/SCCM) basics - software distribution, collections.
- Basic PowerShell scripting for Windows endpoint tasks.
- Understanding of Windows 10/11 MDM management concepts.
- Experience with device enrolment workflows including Autopilot and manual enrolment.
- Knowledge of patch management workflows and Windows Update for Business basics.
- Familiarity with Microsoft Entra ID device registration and Hybrid Join concepts.
- Experience troubleshooting application deployment failures and policy conflicts.

**Soft Skills and Leadership:**

- Strong customer service orientation and communication with end users and help desk.
- Methodical troubleshooting approach with attention to detail.
- Willingness to document processes and share knowledge with the team.

**Technology Proficiency Levels:**

- **Expert level required:** Microsoft Intune configuration profiles, compliance policies, and app deployment, Windows Autopilot device registration and enrolment workflows, PowerShell scripting for endpoint remediation tasks
- **Proficient level required:** Microsoft Endpoint Configuration Manager (MECM) software distribution and collections, Microsoft Entra ID device registration and Hybrid Join, Windows Update for Business and Autopatch
- **Working Knowledge required:** Apple Business Manager and iOS/macOS MDM management, Microsoft Defender for Endpoint basics, Microsoft 365 service integration
- **Awareness level expected:** Zero Trust endpoint security concepts, Windows 365 Cloud PC, Microsoft Intune Suite advanced features

## Typical Day-to-Day Activities

- Monitoring device compliance dashboard and actioning non-compliant devices.
- Processing application deployment requests and troubleshooting failures.
- Handling escalated help desk tickets related to device enrolment and policy issues.
- Registering new devices in Autopilot and supporting provisioning.
- Running patch compliance reports and following up on stalled patch deployments.
- Updating knowledge base articles and runbooks.
- Attending team stand-ups and sprint ceremonies.

## Key Performance Indicators

- Device compliance rate on assigned platforms
- Patch deployment success rate within SLA
- Application deployment success rate
- Help desk escalation response and resolution time
- Accuracy and completeness of documentation maintained

## Remote Work Considerations

- **Remote Eligibility:** Largely remote - Intune is cloud-native; some on-site needed for physical device handling.
- **Collaboration Tools:** Microsoft Teams, Intune Admin Centre, ServiceNow, Jira.
- **On-Site Requirements:** Occasional on-site for Autopilot device provisioning and hardware builds.
- **Time Zone Flexibility:** Standard business hours.
- **On-Call / Operational Demands:** May be included in on-call rotation for critical endpoint incidents depending on team size.
