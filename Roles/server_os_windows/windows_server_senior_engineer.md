## Role Overview

The Windows Server Senior Engineer leads complex implementations and optimizations for Tier 1 Windows Server environments, excluding Tier 0 infrastructure (domain controllers and servers involved in directory services) which falls under the exclusive responsibility of the Directory Services team.

## Role Scope & Boundaries

- **Scope of Influence:** Domain — advanced Windows solution delivery within the Windows Server Architect's reference architecture
- **Experience Anchor:** 5+ years in Windows systems engineering with demonstrated independent delivery — operates independently within the Architect's reference architecture
- **Out of Scope:** Windows platform architecture and standards (Architect-owned); Azure hybrid solution architecture (Azure Cloud Senior Engineers-owned, this role coordinates with it); cross-domain solution design ownership (Senior Engineers from other platforms-owned, this role coordinates with them)
- **Escalates To:** Windows Server Architect — solution design and validation exceptions
- **Escalated To By:** Windows Server Engineers on technical implementation issues

## Business Impact

- **Business Objective:** Leads complex Windows Server implementations, PowerShell automation, and HA configurations ensuring highly available, secure, and well-optimised Windows infrastructure for critical business application workloads
- **Value Metrics:** Server availability, complex incident resolution time, PowerShell automation coverage, patch compliance, failover cluster success rates, migration success rates
- **Key Stakeholders:** Windows Server Architect, application teams, cloud senior engineers, security engineers, Windows Server Product Owner
- **Processes Supported:** Complex Windows Server deployments, automation development, HA/failover cluster implementation, security hardening, migration execution, engineer mentorship

## Key Responsibilities

- Design and implement complex Windows Server solutions with the Architect
- Develop automation frameworks and scripts for Windows Server management
- Lead complex troubleshooting and problem resolution for critical incidents
- Create and maintain Windows infrastructure standards and procedures
- Perform capacity planning and performance optimization for Windows services
- Provide technical mentorship to Windows Server Engineers
- Evaluate and test new Windows technologies and features
- Support the Product Owner in backlog refinement and technical estimation

## Remote Work Considerations

- **Remote Eligibility:** Fully remote eligible; Windows Server senior engineering is performed through remote management tools
- **Collaboration Tools:** Microsoft Teams, Jira, GitHub, Windows Admin Center, Azure Arc, PowerShell, DSC, monitoring dashboards
- **On-Site Requirements:** Not required; all Windows Server management is remote
- **Time Zone Flexibility:** Core business hours with flexibility for maintenance windows and planned failover testing
- **On-Call / Operational Demands:** On-call rotation for critical Windows Server failures, major performance incidents, and high-priority security vulnerabilities affecting business-critical systems
