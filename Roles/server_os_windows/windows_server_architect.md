## Role Overview

The Windows Server Architect designs and defines the strategic direction for the organization's Windows Server infrastructure. This role creates architectural blueprints, standards, and reference models for Windows environments, ensuring they meet business requirements for performance, scalability, reliability, and security while aligning with broader IT strategy and enterprise architecture.

## Role Scope & Boundaries

- **Scope of Influence:** Domain-wide — Windows Server platform architecture and technology standards across the chapter
- **Experience Anchor:** 8+ years in Windows systems architecture with demonstrated architecture-level delivery — operates independently on domain-wide Windows architecture decisions
- **Out of Scope:** Linux Server architecture (Linux Server Architect-owned — a parallel, non-Windows OS ladder); Active Directory identity architecture (Windows Active Directory Architect-owned, this role aligns to it); server hardware specification (Server Hardware Architect-owned, this role consumes it)
- **Escalates To:** Cloud, Platform & Infrastructure Chapter Lead — chapter-wide priorities and cross-domain investment decisions
- **Escalated To By:** Windows Server Engineers on implementation of architectural standards

## Business Impact

- **Business Objective:** Designs enterprise Windows Server architectures ensuring scalable, secure, and performant infrastructure supporting critical business applications, hybrid cloud integration, and regulated-environment compliance
- **Value Metrics:** Architectural standards adoption rate, Windows Server availability improvements, security audit pass rates, cost efficiency of Windows licensing and infrastructure, architecture quality review scores
- **Key Stakeholders:** CTO, IT leadership, application architects, security architects, cloud architects, Windows Server Product Owner
- **Processes Supported:** Windows Server architecture standards governance, platform migration and transformation, HA/DR design, security hardening strategy, version lifecycle planning, Azure hybrid integration

## Key Responsibilities

- Develop and maintain Windows Server architecture standards and patterns
- Design scalable, resilient, and secure Windows infrastructure solutions
- Create migration and transformation strategies for Windows environments
- Establish governance for Windows Server deployments and configurations
- Provide technical leadership and direction to Windows engineering teams
- Evaluate new Windows technologies and recommend adoption strategies
- Design high-availability and disaster recovery solutions for Windows systems
- Develop reference architectures for Windows Server deployments
- Ensure compliance with security policies and regulatory requirements
- Optimize cost and performance of Windows infrastructure
