## Role Overview

The Windows Server Architect designs and defines the strategic direction for the organization's Windows Server infrastructure. This role creates architectural blueprints, standards, and reference models for Windows environments, ensuring they meet business requirements for performance, scalability, reliability, and security while aligning with broader IT strategy and enterprise architecture.

## Business Impact

- **Business Objective:** Designs enterprise Windows Server architectures ensuring scalable, secure, and performant infrastructure supporting critical business applications, hybrid cloud integration, and regulated-environment compliance
- **Value Metrics:** Architectural standards adoption rate, Windows Server availability improvements, security audit pass rates, cost efficiency of Windows licensing and infrastructure, architecture quality review scores
- **Key Stakeholders:** CTO, IT leadership, application architects, security architects, cloud architects, Windows Server Product Owner
- **Processes Supported:** Windows Server architecture standards governance, platform migration and transformation, HA/DR design, security hardening strategy, version lifecycle planning, Azure hybrid integration

## Key Responsibilities

- Develop and maintain Windows Server architecture standards and patterns
- Design scalable, resilient, and secure Windows infrastructure solutions
- Create migration and transformation strategies for Windows environments
- Establish governance for Windows Server deployments and configurations
- Provide technical leadership and direction to Windows engineering teams
- Evaluate new Windows technologies and recommend adoption strategies
- Design high-availability and disaster recovery solutions for Windows systems
- Develop reference architectures for Windows Server deployments
- Ensure compliance with security policies and regulatory requirements
- Optimize cost and performance of Windows infrastructure

## Key Decisions and Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Windows Server architecture standards, reference designs, and platform technology selection | Enterprise architecture and broader IT infrastructure strategy |
| Windows Server security architecture, hardening standards, and compliance design | Enterprise security governance and regulatory compliance |
| Hybrid cloud and Azure integration design for Windows Server workloads | Cloud platform architecture and Azure adoption strategy |

## Required Skills & Qualifications

- Extensive experience with Windows Server architecture and design
- Deep understanding of Active Directory design and federation services
- Strong knowledge of Windows security principles and hardening
- Experience with Windows clustering and high-availability solutions
- Knowledge of Windows performance optimization and capacity planning
- Understanding of virtualization and containerization on Windows
- Experience with cloud integration for hybrid Windows environments
- Strong analytical and problem-solving skills
- Excellent communication and documentation abilities
- Strategic thinking and long-term planning capabilities

**Technology Proficiency Levels:**

- **Expert level required:** Windows Server (2019/2022/2025) advanced architecture, Active Directory Domain Services design, Windows Server Failover Clustering, PowerShell and DSC automation frameworks
- **Proficient level required:** Azure Stack/hybrid services integration, Hyper-V virtualization, Storage Spaces Direct and Storage Replica, Microsoft Endpoint Configuration Manager, Windows security hardening standards
- **Working Knowledge required:** Azure Arc for hybrid management, Windows Admin Center, Windows Server containers and Docker integration
- **Awareness level expected:** Azure Stack HCI evolution, Kubernetes on Windows, Microsoft Entra hybrid identity patterns

## Remote Work Considerations

- **Remote Eligibility:** Fully remote eligible; architecture work is design, documentation, and consultation focused with remote access to management tools
- **Collaboration Tools:** Microsoft Teams, Jira, Confluence, Windows Admin Center, PowerShell, Azure Arc, and design tools
- **On-Site Requirements:** Occasional on-site for data centre architecture workshops, new platform assessments, or DR test validation
- **Time Zone Flexibility:** Standard business hours with flexibility for cross-team architecture reviews
- **On-Call / Operational Demands:** Not typically on-call; on escalation path for architectural guidance during critical Windows platform outages
