## Role Overview

The Windows Server Product Owner manages the product backlog and roadmap for all Tier 1 Windows Server platforms, excluding Tier 0 infrastructure (domain controllers and servers involved in directory services) which falls under the exclusive responsibility of the Directory Services team.

## Business Impact

- **Business Objective:** Manages the Windows Server platform roadmap ensuring stable, secure, and cost-efficient server infrastructure enabling reliable application delivery and business operations
- **Value Metrics:** Platform availability, patch compliance rate, provisioning turnaround time, roadmap delivery rate, licensing cost optimisation, stakeholder satisfaction with server services
- **Key Stakeholders:** IT leadership, application product owners, security teams, Microsoft account team, cloud platform POs, finance
- **Processes Supported:** Windows Server backlog management, version lifecycle planning, security compliance strategy, capacity planning, Microsoft vendor management, agile ceremonies

## Key Responsibilities

- Develop and maintain the product backlog for Windows Server infrastructure
- Prioritize features, improvements, and technical debt remediation
- Define acceptance criteria for Windows Server infrastructure deliverables
- Lead sprint planning, reviews, and retrospectives for the Windows Server team
- Coordinate with stakeholders to gather requirements and manage expectations
- Align Windows Server roadmap with organizational technology strategy
- Manage resource allocation and capacity planning for the Windows Server team
- Track and report on key metrics and service level objectives

## Key Decisions and Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Windows Server product backlog prioritisation and platform technology roadmap | Architecture recommendations and platform technical design |
| Windows Server lifecycle management, version upgrade planning, and OS end-of-support strategy | Enterprise architecture direction and cross-platform infrastructure strategy |
| Microsoft license governance, cost management, and vendor relationship management | Enterprise IT strategy and platform investment decisions |

## Required Skills & Qualifications

**Technical Skills:**

- Strong understanding of Windows Server technologies and enterprise applications
- Experience with Agile methodologies and product ownership
- Knowledge of IT service management and operations
- Background in Windows infrastructure architecture or engineering
- Strong communication and stakeholder management skills
- Ability to translate business needs into technical requirements
- Experience with project management and resource planning
- Familiarity with IT governance and compliance frameworks

**Soft Skills and Leadership:**

- Translates Windows Server platform capabilities and lifecycle risks into clear business value and risk-based investment cases for application teams and IT leadership
- Builds collaborative relationships with the Windows Server Architect, engineers, application product owners, security teams, and Microsoft account management to align platform delivery with organizational needs
- Makes evidence-based backlog decisions using platform metrics, security compliance data, licensing cost analysis, and Microsoft technology lifecycle information

**Technology Proficiency Levels:**

- **Expert level required:** Windows Server lifecycle management and Microsoft version roadmap, Microsoft licensing portals and cost management, Jira/Azure DevOps backlog and sprint management
- **Proficient level required:** Windows Server platform concepts (AD, GPO, WSUS, Failover Clustering), Azure hybrid services awareness, PowerShell scripting concepts, ITSM platforms (ServiceNow)
- **Working Knowledge required:** Microsoft Endpoint Configuration Manager concepts, Azure Arc and hybrid management, Windows Server security frameworks (CIS, NIST)
- **Awareness level expected:** Azure Stack HCI adoption trends, Windows Server containerization, Infrastructure as Code approaches
