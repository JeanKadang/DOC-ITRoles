## Role Overview

The .NET Architect designs comprehensive strategies and architectures for the organization's .NET ecosystem. This role establishes the technical vision for .NET platforms, frameworks, and applications, creating architectures that balance performance, scalability, security, and developer productivity while aligning with business objectives.

## Role Scope & Boundaries

- **Scope of Influence:** Domain-wide — .NET platform architecture standards and technology stack decisions across the chapter
- **Experience Anchor:** 8+ years in .NET engineering or software architecture with demonstrated architecture-level delivery — operates independently on domain-wide .NET architecture decisions
- **Out of Scope:** Enterprise-wide technology standards (Enterprise Architects-owned); .NET security control implementation detail (Security Architects-owned, this role aligns to it); cloud deployment architecture (Cloud Architects-owned)
- **Escalates To:** DevOps & Delivery Chapter Lead — chapter-wide priorities, cross-domain boundary disputes, and investment decisions beyond .NET platform scope
- **Escalated To By:** .NET Senior Engineers on design exceptions and standards clarification

## Business Impact

- **Business Objective:** Establishes .NET platform standards and frameworks enabling application teams to build secure, performant, and maintainable enterprise applications that deliver business value on Microsoft technology investments
- **Value Metrics:** Application delivery speed, code quality and maintainability scores, technical debt reduction, .NET platform adoption rates, security vulnerability rates in .NET applications
- **Key Stakeholders:** Enterprise Architects, application development teams, DevOps, Security Architects, Azure Cloud Architect, business unit application owners
- **Processes Supported:** Application design review, .NET standards governance, platform modernization programs, cloud-native .NET deployment, security code review gates

## Key Responsibilities

- Design comprehensive .NET platform architectures
- Develop technical strategies for .NET standards and frameworks
- Create reference architectures for .NET applications
- Design governance frameworks for .NET development
- Establish .NET security and compliance architectures
- Design .NET modernization and cloud migration strategies
- Evaluate new .NET technologies and frameworks
- Provide technical leadership for .NET initiatives

## Key Decisions & Accountabilities

| .NET security patterns, NuGet dependency policies, and code quality and scanning standards | Azure platform design and cloud-native .NET deployment architecture |
