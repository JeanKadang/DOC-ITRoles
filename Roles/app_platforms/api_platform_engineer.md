## Role Overview

The API Platform Engineer implements and maintains API management solutions across the organization. Working with the API Platform Senior Engineers and Architects, this role ensures reliable, secure, and optimized API solutions supporting various business applications and services.

## Role Scope & Boundaries

- **Scope of Influence:** Team — execution of API implementation and deployment tasks to defined standards
- **Experience Anchor:** 1-3 years in API or software engineering — works under guidance, building toward independent delivery
- **Out of Scope:** API platform architecture and standards (Senior Engineers and the Architect-owned); API security control design; integration guidance strategy beyond assigned implementation tasks
- **Escalates To:** API Platform Senior Engineer — design-level questions and complex implementation issues
- **Escalated To By:** API Consumers on integration guidance and implementation support requests

## Business Impact

- **Business Objective:** Maintains API gateway configurations and developer portal content ensuring reliable, secure, and well-documented API services that enable consumers to integrate efficiently
- **Value Metrics:** API platform availability, API response time metrics, documentation quality scores, consumer support ticket volume, certification compliance rates
- **Key Stakeholders:** API Platform Senior Engineer, application development teams, security team, external API consumers
- **Processes Supported:** API gateway configuration and operations, API documentation maintenance, API security policy configuration, monitoring and alerting, consumer support

## Key Responsibilities

- Implement API gateway configurations and policies
- Develop and maintain API documentation and developer portals
- Configure API authentication and authorization mechanisms
- Set up API monitoring and alerting
- Assist with API testing and validation
- Implement API security controls and policies
- Troubleshoot API integration issues
- Support API consumers with implementation guidance
- Maintain API lifecycle management processes
- Assist with API analytics and reporting

## Key Decisions and Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Day-to-day API gateway configuration, policy application, and testing within approved standards | Technical implementation approach and API architecture decisions |
| API documentation, developer portal content, and consumer onboarding guides | API standards and governance policy design |
| API monitoring setup, alerting configuration, and routine incident response | API platform tool selection and strategic roadmap |

## Required Skills & Qualifications

- Experience with API gateway platforms
- Knowledge of REST and/or GraphQL API design principles
- Understanding of API security protocols (OAuth, JWT, API keys)
- Familiarity with API documentation standards (OpenAPI/Swagger)
- Basic knowledge of microservices architecture
- Experience with API testing tools
- Understanding of CI/CD for API deployment
- Relevant API development or management certifications

**Technology Proficiency Levels:**

- **Expert level required:** API gateway configuration and policy management (Apigee, Kong, or Azure API Management), REST API design principles and OpenAPI/Swagger documentation, API authentication protocols (OAuth 2.0, JWT, API keys)
- **Proficient level required:** Postman (API testing, documentation, and consumer support), API monitoring and alerting tools, CI/CD pipelines for API deployment, GraphQL implementation basics
- **Working Knowledge required:** Developer portal content management and consumer onboarding, API transformation and mediation tools, version control for API artefacts (Git/GitHub)
- **Awareness level expected:** AsyncAPI for event-driven API documentation, GraphQL Federation, gRPC fundamentals for high-performance service APIs
