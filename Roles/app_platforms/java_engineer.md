## Role Overview

The Java Engineer implements and maintains Java-based applications and platform components across the organization. Working with the Java Senior Engineers and Architects, this role ensures reliable, secure, and optimized Java solutions supporting various business applications and services.

## Role Scope & Boundaries

- **Scope of Influence:** Team — execution of Java implementation tasks to defined standards
- **Experience Anchor:** 1-3 years in Java or software engineering — works under guidance, building toward independent delivery
- **Out of Scope:** Java platform architecture and standards (Senior Engineers and the Architect-owned); data access layer design (Database Engineers-owned); deployment pipeline design (DevOps Engineers-owned)
- **Escalates To:** Java Senior Engineer — design-level questions and complex implementation issues
- **Escalated To By:** application teams on Java implementation support requests

## Business Impact

- **Business Objective:** Builds and maintains Java application features and services delivering business functionality reliably and securely to meet organizational and end-user needs
- **Value Metrics:** Feature delivery velocity, unit test coverage, defect density, build quality scores, adherence to Java coding standards
- **Key Stakeholders:** Java Senior Engineer, application product owners, QA teams, DevOps teams
- **Processes Supported:** Feature development and delivery, unit and integration testing, code review participation, CI/CD deployment, technical documentation

## Key Responsibilities

- Implement Java applications and services following design standards
- Develop and maintain Java components and shared libraries
- Troubleshoot and resolve Java application issues
- Write unit and integration tests for Java code
- Implement security controls for Java applications
- Optimize application performance and resource usage
- Create and update technical documentation
- Support application deployment and operations

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Feature implementation within established Java patterns and coding standards | Technical design approach and solution architecture decisions |
| Unit test coverage for developed components and bug resolution within assigned scope | Java platform standards improvements and framework enhancement suggestions |
| Technical documentation for developed code, REST APIs, and configuration | Development workflow and tooling improvement ideas |

## Required Skills & Qualifications

- Experience with Java development
- Knowledge of object-oriented programming concepts
- Understanding of software development methodologies
- Familiarity with relational databases and data access
- Basic knowledge of web services and APIs
- Understanding of version control systems
- Experience with testing frameworks
- Relevant certifications in Java development

**Technology Proficiency Levels:**

- **Expert level required:** Java language (JDK 8-17) and object-oriented programming principles, Spring Framework (Spring Boot, Spring MVC, Spring Data), JUnit and Mockito (unit and integration testing)
- **Proficient level required:** Maven or Gradle (build tools and dependency management), JPA/Hibernate for relational data access, RESTful API development (REST controllers, HTTP standards), SQL database connectivity (JDBC)
- **Working Knowledge required:** Git version control and branching basics, CI/CD pipeline basics (Jenkins or GitLab CI), Docker container fundamentals for Java applications
- **Awareness level expected:** Kubernetes for Java deployment targets, Spring Cloud for microservices patterns, reactive programming with Spring WebFlux
