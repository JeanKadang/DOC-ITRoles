## Role Overview

The .NET Engineer implements and maintains .NET-based applications and platform components across the organization. Working with the .NET Senior Engineers and Architects, this role ensures reliable, secure, and optimized .NET solutions supporting various business applications and services.

## Role Scope & Boundaries

- **Scope of Influence:** Team — execution of .NET implementation tasks to defined standards
- **Experience Anchor:** 1-3 years in .NET or software engineering — works under guidance, building toward independent delivery
- **Out of Scope:** .NET platform architecture and standards (Senior Engineers and the Architect-owned); data access layer design (Database Engineers-owned); deployment pipeline design (DevOps Engineers-owned)
- **Escalates To:** .NET Senior Engineer — design-level questions and complex implementation issues
- **Escalated To By:** application teams on .NET implementation support requests

## Business Impact

- **Business Objective:** Builds and maintains .NET application components delivering business features reliably, securely, and on schedule to support organizational productivity and user needs
- **Value Metrics:** Feature delivery velocity, unit test coverage rates, defect density, code quality scores, adherence to .NET platform standards
- **Key Stakeholders:** .NET Senior Engineer, application product owners, QA teams, DevOps teams
- **Processes Supported:** Feature development and delivery, unit and integration testing, code review participation, CI/CD deployment pipelines, technical documentation

## Key Responsibilities

- Implement .NET applications and services following design standards
- Develop and maintain .NET components and shared libraries
- Troubleshoot and resolve .NET application issues
- Write unit and integration tests for .NET code
- Implement security controls for .NET applications
- Optimize application performance and resource usage
- Create and update technical documentation
- Support application deployment and operations

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
