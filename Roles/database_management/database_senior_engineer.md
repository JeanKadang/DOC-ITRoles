## Role Overview

The Database Senior Engineer leads the implementation and optimization of complex database environments. This role provides technical leadership for database deployments, migrations, and performance tuning while working closely with architects to translate database designs into effective implementations.

## Role Scope & Boundaries

- **Scope of Influence:** Domain — advanced database solution design and delivery within the Database Architect's reference architecture
- **Experience Anchor:** 5+ years in database engineering with demonstrated independent delivery — operates independently within the Architect's reference architecture
- **Out of Scope:** Database platform architecture and technology standards (Architect-owned); cloud database service selection (Cloud Senior Engineers-owned, this role coordinates with it); reliability engineering tooling strategy (Database Reliability Engineer-owned, this role coordinates with it)
- **Escalates To:** Database Architect — solution design and implementation strategy exceptions
- **Escalated To By:** Database Engineers on complex database technology issues

## Business Impact

- **Business Objective:** Leads complex database implementations and performance optimizations ensuring highly available, high-performance database services that support critical business applications and data workloads
- **Value Metrics:** Database availability, query performance improvements, HA/DR implementation success, automation coverage, incident resolution time, migration success rates
- **Key Stakeholders:** Database Architect, application development teams, cloud teams, data governance, security engineers
- **Processes Supported:** Complex database design and implementation, advanced performance tuning, HA/DR delivery, database automation, data migration and integration, mentorship of database engineers

## Key Responsibilities

- Design and implement complex database solutions based on architectural guidance
- Develop database deployment automation and Infrastructure as Code approaches
- Implement advanced high availability and disaster recovery solutions
- Lead performance tuning and optimization for critical databases
- Create and maintain database standards and procedures
- Troubleshoot complex database performance and availability issues
- Implement data migration and integration strategies
- Provide technical mentorship to Database Engineers

## Required Skills & Qualifications

**Technical Skills:**

- Extensive experience with multiple database platforms
- Advanced knowledge of database internals and performance tuning
- Strong skills in database high availability and disaster recovery
- Experience with database automation and Infrastructure as Code
- Understanding of data modeling and design principles
- Knowledge of database security best practices
- Experience with large-scale database migrations
- Relevant advanced certifications for database platforms

**Soft Skills and Leadership:**

- Communicates complex database technical findings, designs, and performance analysis clearly to architects, product owners, and application teams; produces thorough technical documentation
- Leads cross-functional collaboration with application, cloud, infrastructure, and security teams on complex database projects and migrations; mentors Database Engineers on advanced operations and architecture
- Applies rigorous analytical approaches to root-cause database performance and availability issues; proactively identifies database modernization and automation opportunities that reduce operational risk

**Technology Proficiency Levels:**

- **Expert level required:** Advanced relational database performance tuning (Oracle, SQL Server, or PostgreSQL — execution plans, advanced indexing, and buffer pool optimisation), database HA and DR implementation (SQL Server Always On AG, Oracle Data Guard, or PostgreSQL streaming replication), database automation and Infrastructure as Code for database deployments
- **Proficient level required:** NoSQL database platforms at production scale (MongoDB, Cassandra — administration and tuning), cloud database migration strategies (on-prem to AWS RDS, Azure SQL, or GCP Cloud SQL), data replication technologies (logical replication and CDC patterns)
- **Working Knowledge required:** Advanced backup and recovery strategies (point-in-time recovery and cross-region backup), database security hardening (TDE, column encryption, row-level security), containerised database deployment patterns
- **Awareness level expected:** NewSQL and distributed database patterns (CockroachDB, TiDB), AI-assisted query tuning tools, database DevOps and schema migration practices (Flyway, Liquibase)
