## Role Overview

The Database Engineer implements and maintains database systems across the organization. Working with the Database Architect and Product Owner, this role ensures reliable, secure, and optimized database environments supporting various business applications.

## Business Impact

- **Business Objective:** Implements and maintains database systems ensuring reliable, secure data storage and retrieval that supports application workloads and business operations
- **Value Metrics:** Database availability, backup success rates, patch compliance, query response times, incident resolution time, provisioning turnaround
- **Key Stakeholders:** Database Senior Engineers, application development teams, service desk, infrastructure teams
- **Processes Supported:** Database instance provisioning, routine maintenance and patching, backup and recovery, monitoring, security hardening, change management

## Key Responsibilities

- Install and configure database systems according to requirements
- Implement database security controls and access management
- Perform routine database maintenance operations
- Monitor database performance and resolve issues
- Execute database backup and recovery procedures
- Assist with database migrations and upgrades
- Implement basic database scripts and procedures
- Document database configurations and operational procedures

## Key Decisions and Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Day-to-day database provisioning, configuration, and operational tasks within established standards | Technical configuration decisions, architecture choices, and design recommendations |
| Database backup and recovery procedure execution and restoration testing | High availability design and disaster recovery architecture for database environments |
| Operational documentation accuracy and change management execution for database tasks | Automation scripting approaches, performance optimization strategies, and schema design improvements |

## Required Skills & Qualifications

**Technical Skills:**

- Experience with relational database systems (SQL Server, Oracle, PostgreSQL, etc.)
- Knowledge of SQL and database query languages
- Understanding of database security principles
- Familiarity with database backup and recovery processes
- Basic knowledge of database performance monitoring
- Understanding of storage requirements for databases
- Awareness of high availability concepts
- Relevant certifications for specific database platforms

**Soft Skills and Leadership:**

- Communicates operational status, incident progress, and database documentation clearly to senior engineers, application teams, and the service desk requesting database support
- Collaborates effectively with server, storage, network, and application teams to fulfil database provisioning and maintenance requirements across teams
- Applies methodical troubleshooting to diagnose database connectivity, performance, and availability incidents, escalating complex issues to senior engineers with organized technical context

**Technology Proficiency Levels:**

- **Expert level required:** Relational database administration (Oracle, SQL Server, or PostgreSQL — instance management, backup/recovery, and patching), SQL and query language proficiency (DML, DDL, stored procedures, and views), database security controls (access management, RBAC, and auditing configuration)
- **Proficient level required:** Database backup and recovery procedure execution and restoration testing, database performance monitoring tools (execution plans, query analysis, and space utilisation), database provisioning and standard configuration management
- **Working Knowledge required:** High availability concepts (SQL Server Always On AG, Oracle RAC basics, or PostgreSQL streaming replication), cloud database services (Azure SQL, AWS RDS basics), database migration and upgrade tooling
- **Awareness level expected:** NoSQL database platforms (MongoDB, Redis fundamentals), database automation scripting (Python/PowerShell), container-based database deployments

## Remote Work Considerations

- **Remote Eligibility:** Fully remote eligible; database administration and maintenance is performed through remote management tools
- **Collaboration Tools:** Microsoft Teams, Jira, SSMS/DBeaver/pgAdmin/SQL Developer, and database monitoring dashboards
- **On-Site Requirements:** Occasional on-site access may be needed for physical storage configuration tasks or disaster recovery failover testing in-lab
- **Time Zone Flexibility:** Core business hours alignment with the database operations team
- **On-Call / Operational Demands:** Participates in on-call rotation for database incidents affecting application availability and data service disruptions
