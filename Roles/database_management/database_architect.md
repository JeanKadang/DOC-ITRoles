## Role Overview

The Database Architect designs comprehensive data management strategies and architectures for the organization. This role establishes the technical vision for database implementations, creating architectures that balance performance, scalability, security, and operational excellence while ensuring data integrity and availability.

## Role Scope & Boundaries

- **Scope of Influence:** Domain-wide — database platform architecture, technology selection, and data persistence standards across the chapter
- **Experience Anchor:** 8+ years in database architecture or engineering with demonstrated architecture-level delivery — operates independently on domain-wide database architecture decisions
- **Out of Scope:** Enterprise-wide data strategy (Enterprise Architects-owned, this role implements data persistence within it); application-level data access patterns (Application Architects-owned, this role provides persistence standards to them); database security control implementation (Security Architects-owned, this role aligns to it)
- **Escalates To:** Data & AI Chapter Lead — chapter-wide priorities and cross-domain investment decisions
- **Escalated To By:** Database Senior Engineers on solution design and implementation strategy

## Business Impact

- **Business Objective:** Designs enterprise database architectures ensuring data integrity, high performance, and availability across relational and NoSQL platforms to support reliable application delivery and business intelligence
- **Value Metrics:** Database availability, query performance improvements, storage efficiency, data security compliance scores, modernization progress (on-prem to cloud DB migration)
- **Key Stakeholders:** CTO, application architects, data governance teams, security architects, IT leadership
- **Processes Supported:** Database standards governance, data modernization planning, HA/DR design, data security and compliance, migration architecture and execution

## Key Responsibilities

- Design comprehensive database architectures across platforms
- Develop technical strategies for database modernization
- Create reference architectures for database implementations
- Design data governance and security frameworks
- Establish high availability and disaster recovery strategies
- Design data integration and migration architectures
- Evaluate new database technologies and approaches
- Provide technical leadership for database initiatives

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Database architecture standards, platform selection criteria, and enterprise database reference designs | Application data architecture patterns and cross-domain data persistence strategy |
| Database security framework, encryption standards, access control patterns, and compliance controls | Enterprise security governance and regulatory compliance strategy for data |
| Database modernization strategy, cloud-native DB adoption approach, and migration framework | Organizational data strategy, data governance policies, and enterprise data architecture direction |

## Required Skills & Qualifications

- Deep knowledge of multiple database technologies and architectures
- Extensive experience with data modeling and design
- Strong understanding of enterprise architecture principles
- Advanced knowledge of database security and compliance
- Experience with database performance optimization
- Understanding of distributed database systems
- Knowledge of data governance principles
- Relevant advanced certifications in database technologies

**Technology Proficiency Levels:**

**Expert level required:**

- Relational database architecture (Oracle, SQL Server, or PostgreSQL — design patterns, HA/DR, and query performance tuning)
- data modelling (dimensional, normalised, and data vault patterns for enterprise workloads)
- database security framework design (encryption, access control, and compliance controls)

**Proficient level required:**

- NoSQL database platforms (MongoDB, Cassandra, or Couchbase — architecture patterns and use case selection)
- Database-as-a-Service platforms (Azure SQL, AWS RDS/Aurora, GCP Cloud SQL — migration and adoption strategy)
- database migration tools and cloud database modernisation approaches

**Working Knowledge required:**

- In-memory database technologies (Redis, Memcached — caching and session store patterns)
- distributed database architectures (CockroachDB, Spanner — for globally consistent workloads)
- data replication and synchronisation technologies

**Awareness level expected:**

- NewSQL and HTAP database trends
- AI-assisted query optimisation tools
- database DevOps and schema-as-code practices (Flyway, Liquibase)
