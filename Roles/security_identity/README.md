# Security identity domain

This domain covers identity and access management (IAM) architecture across the organisation. Responsibilities include Microsoft Entra ID design and operations, role-based access control (RBAC) and attribute-based access control (ABAC) design, privileged access management (PAM), identity governance and administration (IGA), federated identity and single sign-on (SSO), and passwordless and phishing-resistant authentication strategies. Roles here are the primary owners of the IAM platform and collaborate closely with `security/` on the wider security controls framework and with `directory_services/` on on-premises identity infrastructure. For platform-spanning security automation and zero trust implementation see `security_cross_platform/`.
