## Role Overview

The Identity Management Engineer implements and maintains identity management systems across the organization. Working with the Identity Management Architect and Product Owner, this role ensures secure, efficient, and well-managed identity services for all users and applications.

## Role Scope & Boundaries

- **Scope of Influence:** Team — execution of identity provisioning and directory operations tasks to defined standards
- **Experience Anchor:** 1-3 years in identity or directory engineering — works under guidance, building toward independent delivery
- **Out of Scope:** Identity management architecture and solution design (Senior Engineers and the Architect-owned); access management (authorization) implementation (Access Management Engineers-owned, this role integrates with it); Windows Server infrastructure operations (Windows Server Engineers-owned, this role coordinates with it)
- **Escalates To:** Identity Management Senior Engineer — design-level questions and complex implementation issues
- **Escalated To By:** application teams on identity integration requests

## Business Impact

- **Business Objective:** Maintains and operates identity management systems ensuring users can authenticate reliably and that identity lifecycle processes run accurately throughout the complete employee journey
- **Value Metrics:** Authentication system uptime, user provisioning and deprovisioning accuracy, federation service reliability, reduction in identity-related helpdesk tickets
- **Key Stakeholders:** Identity Management Senior Engineer, HR, service desk teams, application teams, end users requiring identity and authentication support
- **Processes Supported:** User onboarding and offboarding identity workflows, directory service maintenance, MFA and authentication configuration, identity reporting and audit data generation

## Key Responsibilities

- Deploy and configure identity management solutions
- Implement identity repositories and directory services
- Configure authentication systems and federation services
- Set up identity provisioning and lifecycle workflows
- Troubleshoot and resolve identity-related incidents
- Implement identity management integrations with enterprise applications
- Generate identity reports and audit data
- Document identity management configurations and procedures

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Day-to-day configuration and operation of identity management platforms and directory services | Technical implementation approach and solution architecture decisions |
| Identity provisioning workflows, directory updates, and authentication system configuration | Identity automation strategy and lifecycle policy design decisions |
| Incident troubleshooting and resolution for identity and authentication system issues | Platform selection and identity management architecture decisions |

## Required Skills & Qualifications

**Technical Skills:**

- Experience with identity management tools and platforms
- Knowledge of directory services (Active Directory, LDAP)
- Understanding of authentication protocols and standards
- Familiarity with identity provisioning processes
- Basic scripting skills for identity automation
- Understanding of identity security principles
- Knowledge of federation technologies
- Relevant certifications in identity management or security

**Soft Skills and Leadership:**

- Communicates identity and authentication system issues clearly to end users and technical stakeholders throughout the resolution lifecycle
- Coordinates effectively with HR, access management, and application teams on user lifecycle processes and cross-functional identity workflows
- Troubleshoots identity issues systematically applying root cause analysis techniques to minimize authentication downtime and business disruption

**Technology Proficiency Levels:**

- **Expert level required:** Windows Active Directory, Microsoft Entra ID, Azure MFA
- **Proficient level required:** AD FS/SAML (federation services), Microsoft Entra Connect (sync), LDAP
- **Working Knowledge required:** Identity provisioning tools (SCIM), password management systems
- **Awareness level expected:** OAuth 2.0/OIDC, SailPoint/Saviynt (IGA)

- **Remote Eligibility:** Fully remote eligible with secure administrative access to identity management platforms and directory services
- **Collaboration Tools:** Microsoft Teams, Jira, ServiceNow, Confluence, Active Directory admin tools, Microsoft Entra ID portal, and identity platform consoles
- **On-Site Requirements:** Rarely required; possible for directory services hardware maintenance or initial on-premises identity system deployment and configuration

- **On-Call / Operational Demands:** Participates in on-call rotation for identity system incidents including authentication failures, account lockouts, provisioning errors, and directory synchronization issues
