## Role Overview

The Windows Active Directory Product Owner manages the service roadmap and planning for all Tier 0 infrastructure, including domain controllers and all servers involved in directory services, which fall under the exclusive responsibility of the Directory Services team.

## Role Scope & Boundaries

- **Scope of Influence:** Domain — Active Directory / directory services platform backlog, modernisation roadmap, and delivery prioritisation
- **Experience Anchor:** 5+ years in product ownership or technical product management — operates independently on backlog and roadmap decisions
- **Out of Scope:** Active Directory technical architecture (Windows Active Directory Architect-owned); identity management roadmap (Identity Management Product Owner-owned, this role aligns to it); directory security policy (Security and Compliance teams-owned)
- **Escalates To:** Security & Identity Chapter Lead — budget, headcount, and cross-domain roadmap trade-offs
- **Escalated To By:** Application Product Owners on authentication requirements

## Business Impact

- **Business Objective:** Manages the Active Directory service roadmap and Tier 0 infrastructure backlog ensuring directory services meet security, authentication, and reliability requirements for all users, devices, and applications
- **Value Metrics:** AD availability, authentication success rate, security compliance score, backlog delivery rate, user provisioning throughput, stakeholder satisfaction
- **Key Stakeholders:** IT leadership, CISO, application product owners, Windows Server Product Owner, Identity Management Product Owner, Security and Compliance teams
- **Processes Supported:** AD service backlog prioritisation, upgrade and migration planning, security policy planning, stakeholder requirements gathering, agile ceremonies and sprint planning

## Key Responsibilities

- Develop and maintain the product backlog for Active Directory services
- Prioritize directory services initiatives based on business impact and risk
- Define acceptance criteria for Active Directory deliverables
- Lead sprint planning and agile ceremonies for the AD team
- Engage with business stakeholders to understand identity requirements
- Create and maintain a strategic roadmap for Active Directory evolution
- Manage capacity planning and resource allocation for directory services
- Track and report on directory services health, performance, and security metrics

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| AD service backlog, upgrade roadmap, and Tier 0 lifecycle planning and prioritisation | Architecture technical strategy and design decision-making |
| Directory services SLAs, security compliance objectives, automation targets, and service reporting | Identity Management strategy and integration governance |
| Capacity planning and resource allocation for the directory services team | Enterprise identity governance and hybrid cloud identity strategy |
