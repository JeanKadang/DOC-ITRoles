## Role Overview

The Windows Active Directory Engineer maintains directory services and all Tier 0 Windows servers across the organization. This role has exclusive responsibility for implementing and maintaining domain controllers and all servers involved in directory services.

## Role Scope & Boundaries

- **Scope of Influence:** Team — execution of Active Directory operations and authentication support tasks to defined standards
- **Experience Anchor:** 1-3 years in directory services or Windows infrastructure engineering — works under guidance, building toward independent delivery
- **Out of Scope:** Active Directory architecture and solution design (Senior Engineers and the Architect-owned); broader Windows Server infrastructure ownership (Windows Server Engineers-owned, this role coordinates with it); identity provisioning beyond directory operations (Identity Management Engineers-owned, this role coordinates with it)
- **Escalates To:** Windows Active Directory Senior Engineer — design-level questions and complex implementation issues
- **Escalated To By:** application teams on authentication requirements

## Business Impact

- **Business Objective:** Implements and maintains Active Directory domain controllers and Tier 0 infrastructure ensuring accurate directory configurations and stable authentication services for all users, devices, and applications
- **Value Metrics:** AD availability, user and computer account provisioning time, GPO implementation accuracy, domain controller backup success rate, incident resolution time
- **Key Stakeholders:** Windows Server Engineers, help desk, application teams, Security Engineers, IT support teams
- **Processes Supported:** Domain controller deployment and maintenance, OU and GPO configuration, AD user/computer account lifecycle management, AD backup and recovery, DNS for Active Directory

## Key Responsibilities

- Deploy and configure domain controllers according to specifications
- Implement Active Directory organizational units and group structures
- Configure group policies based on security and management requirements
- Perform routine maintenance on Active Directory infrastructure
- Troubleshoot and resolve directory services incidents
- Execute Active Directory changes, updates, and migrations
- Implement basic PowerShell automation for AD management tasks
- Document Active Directory configurations and operational procedures

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).
