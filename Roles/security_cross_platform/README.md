# Security cross-platform domain

This domain covers security patterns and controls that apply across multiple technology platforms rather than belonging to a single domain. Responsibilities include zero trust architecture design and implementation, cloud security posture management (CSPM), DevSecOps control frameworks that span CI/CD and cloud platforms, software supply chain security (SLSA, SBOM, Sigstore/Cosign), and security automation and policy-as-code tooling. Roles here work closely with `security/` (which owns the general controls framework and SOC architecture) and `security_identity/` (which owns identity and access management) and are the primary point of contact for security concerns that cut across Cloud Platforms, DevOps, and Kubernetes domains.
