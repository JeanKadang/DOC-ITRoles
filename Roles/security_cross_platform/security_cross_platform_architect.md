## Role Overview

The Security Cross-Platform Architect designs and develops comprehensive security frameworks, standards, and architectures that span multiple technology domains. This role ensures consistent security controls and governance across all infrastructure platforms including on-premises servers, cloud environments, container platforms, and virtualization infrastructure.

## Business Impact

- **Business Objective:** Ensures security controls are consistent, coherent, and enforceable across the organisation's entire technology estate — eliminating blind spots that arise from siloed, domain-specific security approaches and reducing the risk of attackers exploiting gaps at platform boundaries.
- **Value Metrics:** Security control consistency score across platforms, reduction in cross-platform security incidents, number of reusable reference architectures adopted by domain teams, security compliance rate across heterogeneous estate, time to apply enterprise-wide security controls.
- **Key Stakeholders:** CISO, domain architects (Windows, Linux, Cloud, Kubernetes), DevOps Architect, Security Product Owner, Enterprise Architecture team, Board Risk Committee.
- **Processes Supported:** Enterprise-wide security governance, cross-domain architecture review, security standards development, zero trust design, regulatory compliance across multi-platform estate.

## Key Responsibilities

- Design cross-platform security architectures that address technical requirements across all technology domains
- Develop security standards, policies, and guidelines that can be consistently applied across diverse platforms
- Collaborate with domain-specific architects (Windows, Linux, Cloud, etc.) to integrate security controls into their domains
- Lead security architecture reviews for complex cross-domain initiatives
- Establish security governance models that work across different technology stacks
- Drive security innovation and modernization across all platforms
- Maintain awareness of emerging security threats and mitigation strategies applicable to multiple domains
- Create reference architectures for common security patterns that span multiple platforms

## Key Decisions and Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Cross-platform security architecture standards, patterns, and controls library | Domain-specific platform architecture decisions (with domain architects) |
| Zero trust framework design and identity fabric strategy across all platforms | Risk appetite and compliance obligations (with CISO / Risk Management) |
| DevSecOps security reference architecture and supply chain security framework | Cloud and infrastructure platform selection decisions |

## Required Skills & Qualifications

**Technical Skills:**

- 8+ years of experience in IT security architecture with cross-platform expertise
- Deep technical knowledge of security controls across Windows, Linux, cloud, and container environments
- Experience designing security solutions that work consistently across multiple technology domains
- Strong understanding of security frameworks (NIST CSF, IEC 62443, ISO 27001, CIS) and their application
- Expert knowledge of identity and access management across diverse platforms
- Experience with security automation and orchestration across multiple environments
- Excellent communication skills to collaborate with domain-specific teams
- Ability to translate complex security requirements into practical cross-platform solutions

**Soft Skills and Leadership:**

- Navigates competing domain team priorities and builds consensus on shared security standards without creating friction.
- Communicates cross-platform security risk clearly to CISO and board-level stakeholders.
- Balances security rigour with engineering pragmatism to produce controls that are both effective and adoptable.

**Technology Proficiency Levels:**

- **Expert level required:** Zero Trust architecture frameworks, SABSA/TOGAF Security, Microsoft Defender XDR
- **Proficient level required:** Microsoft Sentinel, Prisma Cloud/Wiz (multi-cloud CSPM), Microsoft Entra ID (identity fabric)
- **Working Knowledge required:** IaC security tools (Checkov/tfsec), API security gateways, HashiCorp Vault
- **Awareness level expected:** SOAR automation platforms, eBPF-based runtime security
