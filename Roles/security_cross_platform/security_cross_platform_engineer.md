## Role Overview

The Security Cross-Platform Engineer implements and maintains security controls across multiple technology domains. This role ensures the consistent application of security measures in various environments including Windows, Linux, cloud platforms, and container infrastructure, supporting the organization's overall security posture.

## Role Scope & Boundaries

- **Scope of Influence:** Team — execution of cross-platform security control implementation tasks
- **Experience Anchor:** 1-3 years in security engineering — works under guidance, building toward independent delivery
- **Out of Scope:** Cross-platform security standards (Senior Engineers and the Architect-owned); domain-specific security architecture (domain architects-owned, this role receives technical input from them); security incident response ownership (security operations-owned, this role coordinates with it)
- **Escalates To:** Security Cross-Platform Senior Engineer — complex implementations
- **Escalated To By:** operations teams on security maintenance across multiple domains

## Business Impact

- **Business Objective:** Implements and maintains the security controls that protect the organisation's full multi-platform technology estate, ensuring consistent security baselines are applied and maintained across Windows, Linux, cloud, and container environments.
- **Value Metrics:** Security control implementation coverage across platforms, patch compliance rate, vulnerability scan coverage, security alert response time, documentation and runbook completeness.
- **Key Stakeholders:** Security Cross-Platform Senior Engineer, domain operations teams, Security Operations, IT service desk.
- **Processes Supported:** Cross-platform security hardening and patching, vulnerability management, security compliance checking, incident first response (multi-domain), security documentation

## Key Responsibilities

- Implement security controls that work consistently across multiple technology platforms
- Configure and maintain security tools that span different domains
- Execute security hardening procedures across diverse environment types
- Assist with security monitoring and alerting that covers multiple platforms
- Support incident response for security events that impact multiple domains
- Develop and maintain documentation for cross-platform security configurations
- Participate in security assessments across different technology environments
- Apply security patches and updates across multiple platform types

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Routine security control implementation, hardening tasks, and patch application across assigned platforms | Complex cross-platform security design (escalated to Senior Engineer / Architect) |
| Security documentation, runbooks, and configuration records for cross-platform controls | Security policy definition and risk decisions |
| Vulnerability scan execution and first-pass remediation within approved remediation procedures | Security tooling selection and automation architecture |

## Required Skills & Qualifications

**Technical Skills:**

- 3+ years of experience in security implementation across different technology platforms
- Technical knowledge of security controls for Windows, Linux, cloud, and containers
- Experience with security tooling that operates across multiple domains
- Scripting and automation skills (PowerShell, Python, Bash, etc.)
- Understanding of identity and access management across diverse environments
- Knowledge of security compliance requirements and technical controls
- Ability to troubleshoot security issues across different platforms
- Experience with security monitoring and alerting tools

**Soft Skills and Leadership:**

- Communicates security findings and remediation steps clearly to platform engineers across different technical domains.
- Works collaboratively with Windows, Linux, cloud, and container teams to implement security controls without disrupting operations.
- Methodical troubleshooting approach for security configuration drift and cross-platform policy inconsistencies.
