## Role Overview

The AWS Cloud Platform Architect designs, implements, and governs cloud solutions on Amazon Web Services. This role is responsible for creating secure, scalable, and cost-efficient AWS environments that meet business requirements and technical standards.

## Role Scope & Boundaries

- **Scope of Influence:** Domain-wide — AWS platform architecture and technology standards across the chapter
- **Experience Anchor:** 8+ years in AWS or cloud architecture with demonstrated architecture-level delivery — operates independently on domain-wide AWS architecture decisions within the Cloud Lead Architect's cross-platform standards
- **Out of Scope:** Cross-platform architecture consistency (Cloud Lead Architect-owned, this role escalates cross-platform problems to it); underlying compute/OS configuration (Linux Server Architect-owned, this role aligns to it); container orchestration architecture (Kubernetes Architect-owned, this role coordinates EKS with it)
- **Escalates To:** Cloud Lead Architect — complex cross-platform cloud problems
- **Escalated To By:** AWS Cloud Senior Engineers on solution design questions

## Business Impact

- **Business Objective:** Designs scalable, secure, and cost-efficient AWS architectures that enable the organization to rapidly deploy cloud workloads while reducing infrastructure costs and accelerating application delivery
- **Value Metrics:** Cloud infrastructure cost reduction, AWS environment availability, time-to-provision for new workloads, reduction in architectural risks and security findings
- **Key Stakeholders:** CTO/CIO, application development teams, DevOps teams, FinOps, Security and Compliance, business unit leaders
- **Processes Supported:** Application hosting and migration to AWS, CI/CD pipeline infrastructure, disaster recovery, cloud security posture management, FinOps cost governance

## Key Responsibilities

- Design and implement AWS architectures following best practices and Well-Architected Framework
- Develop cloud governance frameworks for AWS environments
- Create and maintain AWS landing zones and account structures
- Optimize AWS resources for cost, performance, and security
- Implement cloud security controls and compliance requirements in AWS
- Design hybrid and multi-cloud connectivity patterns
- Establish cloud monitoring and management strategies
- Architect generative AI and ML workload deployments using Amazon Bedrock and SageMaker
- Provide technical leadership for AWS migrations and modernization initiatives

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| AWS architecture standards, landing zone design, and multi-account strategy | Enterprise security architecture and overall multi-cloud strategy |
| AWS service selection, reference architecture patterns, and IaC standards | Application architecture decisions and modernization approach |
| Cloud governance framework, guardrails, and compliance controls design | Organizational cloud cost management and FinOps practices |

## Required Skills & Qualifications

**Technical Skills:**

- Deep knowledge of AWS services and architectural patterns
- Experience with AWS networking, security, and identity management
- Understanding of Infrastructure as Code using CloudFormation or Terraform
- Knowledge of AWS cost management and optimization techniques
- Experience with CI/CD pipelines for AWS deployments
- Familiarity with compliance frameworks in cloud environments
- Relevant certifications (AWS Certified Solutions Architect Professional)

**Soft Skills and Leadership:**

- Communicates complex cloud architecture trade-offs and recommendations clearly to both technical and non-technical stakeholders
- Collaborates across DevOps, security, networking, and application teams to ensure cloud architectures are implementable and well-governed
- Applies structured thinking to balance cloud innovation opportunities with security, compliance, and operational constraints

**Technology Proficiency Levels:**

**Expert level required:**

- AWS Well-Architected Framework
- AWS Control Tower and multi-account strategy (AWS Organizations)
- AWS networking (Transit Gateway, Direct Connect, PrivateLink, VPC design)
- AWS IAM and security services (GuardDuty, Security Hub, Config, Macie)

**Proficient level required:**

- Infrastructure as Code (CloudFormation, CDK, Terraform/OpenTofu)
- AWS monitoring and observability (CloudWatch, X-Ray, AWS Distro for OpenTelemetry)
- AWS cost management (Cost Explorer, Savings Plans, Reserved Instances, Trusted Advisor)

**Working Knowledge required:**

- Amazon EKS and container orchestration architecture
- Amazon Bedrock and AWS GenAI services architecture

**Awareness level expected:**

- Amazon SageMaker AI/ML platform design patterns
- AWS GovCloud and Digital Sovereignty Pledge compliance patterns for regulated industries

- **Remote Eligibility:** Fully remote eligible; cloud architecture work is design and consultation-focused with no physical infrastructure requirements

- **On-Site Requirements:** Minimal; occasional on-site for strategic planning workshops or hybrid connectivity assessments with networking teams
- **Time Zone Flexibility:** Standard business hours with flexibility for cross-regional architecture reviews and AWS partner engagements
- **On-Call / Operational Demands:** Not typically on-call; available for critical architecture escalations or major incident architectural support
