## Role Overview

The Azure Cloud Engineer implements and maintains cloud resources and services in Microsoft Azure. Working with the Azure Cloud Platform Architect and Product Owner, this role ensures reliable, secure, and optimized Azure environments supporting various business applications and services.

## Role Scope & Boundaries

- **Scope of Influence:** Team — execution of Azure resource provisioning and implementation tasks to defined standards
- **Experience Anchor:** 1-3 years in Azure or cloud engineering — works under guidance, building toward independent delivery
- **Out of Scope:** Azure architecture and solution design (Senior Engineers and the Architect-owned); underlying Windows Server hybrid services ownership (Windows Server Engineers-owned, this role coordinates with it); AKS implementation ownership (Kubernetes Engineers-owned, this role coordinates with it)
- **Escalates To:** Azure Cloud Senior Engineer — design-level questions and complex implementation issues
- **Escalated To By:** application teams on Azure resource requirements

## Business Impact

- **Business Objective:** Provisions and maintains Azure cloud resources providing reliable, secure, and cost-effective infrastructure for business workloads and applications
- **Value Metrics:** Resource provisioning speed, Azure environment uptime, incident resolution time, cost management effectiveness, security compliance adherence
- **Key Stakeholders:** Azure Cloud Senior Engineer, application development teams, Windows/Linux teams, DevOps teams, service desk
- **Processes Supported:** Cloud resource provisioning, Azure virtual machine and PaaS service management, backup and recovery, Azure monitoring and alerting, security control implementation

## Key Responsibilities

- Provision and configure Azure resources according to requirements
- Implement networking, security, and identity configurations in Azure
- Deploy and maintain virtual machines and platform services
- Assist with migration of workloads to Azure
- Monitor and troubleshoot Azure services and resources
- Implement backup and disaster recovery for cloud resources
- Execute infrastructure as code deployments
- Document Azure configurations and operational procedures

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Day-to-day provisioning, configuration, and operations of Azure resources | Technical implementation approach and architecture decisions |
| ARM/Bicep template creation and IaC deployment within approved patterns | Architecture design, service selection, and governance policy |
| Monitoring configuration, alert thresholds, and routine Azure operations | Cloud cost governance policies and security compliance frameworks |

## Required Skills & Qualifications

- Experience with Microsoft Azure services and portal
- Knowledge of Azure networking and security principles
- Familiarity with ARM templates or Bicep
- Understanding of identity management in Azure
- Experience with Azure virtual machines and storage
- Basic PowerShell or Azure CLI skills
- Understanding of cloud cost management principles
- Relevant certifications (Microsoft Certified: Azure Administrator Associate)

**Expert level required:**

**Proficient level required:**

- Azure CLI and PowerShell for resource provisioning and day-to-day operations
- Azure Monitor and Log Analytics for monitoring configuration and alert management
- Azure Storage (Blob, Files, Disks) and Azure Backup for data protection

**Working Knowledge required:**

- Azure Kubernetes Service (AKS) basics for supporting container workloads
- Microsoft Defender for Cloud for security compliance visibility

**Awareness level expected:**

- Azure DevOps pipelines and GitHub Actions for CI/CD integration
- Terraform for Azure as a multi-cloud IaC progression path

## Remote Work Considerations

- **Remote Eligibility:** Fully remote eligible; all Azure management is performed through Azure Portal, CLI, and IaC tooling
- **Collaboration Tools:** Microsoft Teams, Jira, ServiceNow, Confluence, Azure Portal, Azure CLI, Bicep/ARM/Terraform
- **On-Site Requirements:** Not required; Azure infrastructure is fully remote-managed
- **Time Zone Flexibility:** Core business hours alignment; shift or on-call participation may apply for coverage continuity
- **On-Call / Operational Demands:** Participates in on-call rotation for Azure incidents including virtual machine outages, storage failures, and networking issues
