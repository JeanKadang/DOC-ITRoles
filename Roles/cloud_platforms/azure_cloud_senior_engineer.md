## Role Overview

The Azure Cloud Senior Engineer leads the implementation and optimization of complex Azure cloud solutions. This role provides technical leadership for Azure deployments, migrations, and operations while working closely with architects to translate cloud designs into effective implementations.

## Role Scope & Boundaries

- **Scope of Influence:** Domain — advanced Azure solution design and delivery within the Azure Cloud Architect's reference architecture
- **Experience Anchor:** 5+ years in Azure engineering with demonstrated independent delivery — operates independently within the Architect's reference architecture
- **Out of Scope:** Azure platform architecture and technology standards (Architect-owned); underlying Windows host configuration (Windows Senior Engineers-owned, this role coordinates with it); AKS cluster architecture (Kubernetes Senior Engineers-owned, this role coordinates with it)
- **Escalates To:** Azure Cloud Architect — solution design exceptions
- **Escalated To By:** Azure Cloud Engineers on Azure services and best practices

## Business Impact

- **Business Objective:** Leads implementation of complex Azure solutions that deliver reliable, secure, and cost-optimized cloud infrastructure supporting critical business workloads and transformation programs
- **Value Metrics:** Azure environment availability, IaC coverage rate, cloud cost optimization savings, reduction in security findings, incident resolution time
- **Key Stakeholders:** Azure Cloud Architect, DevOps teams, Windows/Linux teams, application teams, security team, FinOps
- **Processes Supported:** Azure infrastructure delivery, CI/CD pipeline operations, Azure security controls, hybrid connectivity, cloud cost management

## Key Responsibilities

- Design and implement complex Azure solutions based on architectural guidance
- Develop comprehensive Infrastructure as Code templates and pipelines
- Create and maintain Azure landing zones and governance structures
- Lead troubleshooting for critical Azure service issues
- Implement advanced security controls and compliance frameworks
- Design and implement complex networking solutions in Azure
- Optimize Azure resources for cost and performance
- Provide technical mentorship to Azure Cloud Engineers

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Technical implementation approach and IaC solution design for Azure workloads | Azure architecture design and long-term platform strategy |
| Azure security configuration, operational standards, and runbook development | Cloud governance policy, subscription design, and management group structure |
| Azure cost optimization actions and resource right-sizing within agreed frameworks | Strategic Azure roadmap and major service adoption decisions |

## Required Skills & Qualifications

- Extensive experience with Azure services and solutions architecture
- Advanced knowledge of Azure networking, security, and identity
- Strong Infrastructure as Code skills (Terraform, ARM/Bicep)
- Experience with Azure DevOps or similar CI/CD platforms
- Deep understanding of cloud governance and cost management
- Knowledge of Azure security best practices and compliance frameworks
- Experience with complex cloud migrations
- Relevant advanced certifications (Microsoft Certified: Azure Solutions Architect Expert)

**Technology Proficiency Levels:**

- **Expert level required:** Infrastructure as Code (Terraform, Bicep, ARM templates) for complex Azure deployments, Advanced Azure networking (ExpressRoute, Virtual WAN, Azure Firewall, Private Endpoints), Azure security services (Microsoft Defender for Cloud, Microsoft Sentinel, Azure Key Vault), Microsoft Entra ID including PIM, Conditional Access, and hybrid identity
- **Proficient level required:** Azure Kubernetes Service (AKS) and container services deployment and management, Azure DevOps and GitHub Actions for CI/CD pipeline implementation, Azure Monitor, Log Analytics, and Application Insights for full-stack observability
- **Working Knowledge required:** Azure Policy and management groups for governance and compliance enforcement, Azure Cost Management and resource right-sizing tools
- **Awareness level expected:** Azure Arc for hybrid and multi-cloud resource management, Azure AI services and Azure OpenAI Service deployment and integration patterns
