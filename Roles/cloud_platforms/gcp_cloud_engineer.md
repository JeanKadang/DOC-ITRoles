## Role Overview

The Google Cloud Engineer implements and maintains cloud resources and services in Google Cloud Platform (GCP). Working with the GCP Cloud Architect and Product Owner, this role ensures reliable, secure, and optimized GCP environments supporting various business applications and services.

## Role Scope & Boundaries

- **Scope of Influence:** Team — execution of GCP resource provisioning and implementation tasks to defined standards
- **Experience Anchor:** 1-3 years in GCP or cloud engineering — works under guidance, building toward independent delivery
- **Out of Scope:** GCP architecture and solution design (Senior Engineers and the Architect-owned); underlying Linux instance configuration ownership (Linux Server Engineers-owned, this role coordinates with it); CI/CD pipeline design (DevOps Engineers-owned, this role integrates with it)
- **Escalates To:** GCP Cloud Senior Engineer — design-level questions and complex implementation issues
- **Escalated To By:** application teams on GCP resource requirements

## Business Impact

- **Business Objective:** Provisions and maintains GCP cloud resources providing reliable, secure, and cost-effective infrastructure for business workloads, data services, and applications
- **Value Metrics:** Resource provisioning time, GCP environment uptime, incident resolution time, cost management effectiveness, security compliance rates
- **Key Stakeholders:** GCP Cloud Senior Engineer, application and data teams, DevOps teams, service desk
- **Processes Supported:** Cloud resource provisioning, GKE cluster operations, GCP storage and database management, monitoring and alerting, security control implementation

## Key Responsibilities

- Provision and configure GCP resources according to requirements
- Implement networking, security, and identity configurations in GCP
- Deploy and maintain compute services and container platforms
- Assist with migration of workloads to GCP
- Monitor and troubleshoot GCP services and resources
- Implement backup and disaster recovery for cloud resources
- Execute infrastructure as code deployments
- Document GCP configurations and operational procedures

## Key Decisions & Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Day-to-day provisioning, configuration, and operation of GCP resources | Technical implementation approach and architectural decisions |
| Terraform/Deployment Manager template creation within established patterns | Architecture design, service selection, and governance policy |
| Monitoring configuration, alerting, and routine GCP operations | Cloud cost governance policies and security compliance frameworks |

## Required Skills & Qualifications

- Experience with GCP services and console
- Knowledge of GCP networking and security principles
- Familiarity with Infrastructure as Code (Terraform, Deployment Manager)
- Understanding of identity management in GCP
- Experience with Compute Engine, GKE, and other core GCP services
- Basic scripting skills (Python, Bash)
- Understanding of cloud cost management principles
- Relevant certifications (Google Cloud Associate Cloud Engineer)

**Technology Proficiency Levels:**

**Expert level required:**

- Google Compute Engine, managed instance groups, and instance lifecycle management
- Google Kubernetes Engine (GKE) for container workload deployment and operations
- Virtual Private Cloud (VPC) networking, firewall rules, Cloud NAT, and Cloud DNS
- Cloud IAM and service accounts for resource access management

**Proficient level required:**

- Terraform and Google Cloud Deployment Manager for infrastructure as code deployments
- Cloud Storage, Cloud SQL, and core GCP storage and database services
- Google Cloud Monitoring, Cloud Logging, and Cloud Trace for observability

**Working Knowledge required:**

- Cloud Functions, Cloud Run, and App Engine for serverless and PaaS workloads
- GCP cost management tools (Billing Console, Budget Alerts, GCP Recommender)

**Awareness level expected:**

- BigQuery and Vertex AI for data and ML workloads
- GCP security services (Security Command Center, VPC Service Controls) for security posture awareness

## Remote Work Considerations

- **Remote Eligibility:** Fully remote eligible; GCP management is performed through web console, gcloud CLI, and IaC tooling
- **Collaboration Tools:** Microsoft Teams or Google Meet, Jira, ServiceNow, Confluence, GCP Console, gcloud CLI, Terraform
- **On-Site Requirements:** Not required; GCP infrastructure is fully remote-managed
- **Time Zone Flexibility:** Core business hours alignment; shift or on-call rotation may apply for coverage continuity
- **On-Call / Operational Demands:** Participates in on-call rotation for GCP incidents including Compute Engine outages, GKE cluster issues, and networking failures
