## Role Overview

The Google Cloud Senior Engineer leads the implementation and optimization of complex Google Cloud Platform (GCP) solutions. This role provides technical leadership for GCP deployments, migrations, and operations while working closely with architects to translate cloud designs into effective implementations.

## Business Impact

- **Business Objective:** Leads implementation of complex GCP solutions delivering reliable, secure, and cost-optimized cloud infrastructure for business workloads and data/analytics platforms
- **Value Metrics:** GCP environment availability, IaC automation coverage, cloud cost optimization savings, security compliance scores, incident resolution time
- **Key Stakeholders:** GCP Cloud Architect, data engineering teams, DevOps teams, application teams, security team, FinOps
- **Processes Supported:** GCP infrastructure delivery, data and analytics platform operations, CI/CD pipeline infrastructure, GCP security controls, cloud cost management

## Key Responsibilities

- Design and implement complex GCP solutions based on architectural guidance
- Develop comprehensive Infrastructure as Code templates and pipelines
- Lead troubleshooting for critical GCP service issues
- Implement advanced security controls in GCP environments
- Design and implement sophisticated networking solutions in GCP
- Optimize GCP resources for cost and performance
- Plan and execute cloud migrations to GCP
- Provide technical mentorship to GCP Cloud Engineers

## Key Decisions and Accountabilities

> Clarifies what this role **owns** (decides independently) vs. **advises on** (input without final authority).

| Owns | Advises On |
|---|---|
| Technical implementation approach and IaC design for GCP solutions | GCP architecture design and long-term platform strategy |
| GCP security configuration, operational standards, and runbook development | Cloud governance policy, project hierarchy, and organization policy design |
| Cloud cost optimization actions and resource right-sizing within agreed frameworks | Strategic GCP roadmap and major service adoption decisions |

## Required Skills & Qualifications

- Extensive experience with GCP services and solutions architecture
- Advanced knowledge of GCP networking, security, and identity
- Strong Infrastructure as Code skills (Terraform, Deployment Manager)
- Experience with CI/CD platforms for GCP deployments
- Deep understanding of cloud governance and cost management
- Knowledge of GCP security best practices and compliance frameworks
- Experience with complex cloud migrations
- Relevant advanced certifications (GCP Professional Cloud Architect)

**Technology Proficiency Levels:**

- **Expert level required:** Google Kubernetes Engine (GKE) and Anthos for container management and hybrid deployments, GCP networking (VPC, Cloud Interconnect, Network Connectivity Center, Cloud Armor), Infrastructure as Code (Terraform, Google Cloud Deployment Manager) for GCP automation, GCP security services (IAM, Security Command Center, VPC Service Controls, Binary Authorization)
- **Proficient level required:** CI/CD for GCP (Cloud Build, GitLab CI, Jenkins) and GitOps integration, GCP monitoring and observability (Cloud Monitoring, Cloud Logging, Cloud Trace, Cloud Profiler), GCP cost management and resource optimization (Billing Console, Recommender, Committed Use Discounts)
- **Working Knowledge required:** Multi-project GCP strategies and organization hierarchy management (folder structure, Org Policy), GCP data services and analytics (BigQuery, Dataflow, Pub/Sub)
- **Awareness level expected:** Vertex AI and Gemini APIs for ML and GenAI workload deployments, GCP Assured Workloads and compliance tooling for regulated industries

## Remote Work Considerations

- **Remote Eligibility:** Fully remote eligible; all GCP engineering work is performed through secure console, gcloud CLI, and IaC toolchain access
- **Collaboration Tools:** Microsoft Teams or Google Meet, Jira, Confluence, GitHub, GCP Console, gcloud CLI, Terraform tooling
- **On-Site Requirements:** Not required; GCP infrastructure is fully managed remotely via secure tooling
- **Time Zone Flexibility:** Core business hours alignment; flexibility for maintenance windows and cross-regional team collaboration
- **On-Call / Operational Demands:** Participates in on-call rotation covering critical GCP platform failures, availability incidents, and security events
